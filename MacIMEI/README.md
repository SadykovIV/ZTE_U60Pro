# ZTE U60Pro Manager 1.20.0 для macOS ARM64

[Описание программы](../docs/APPLICATION.md) · [Требования к модему](../README.md#требования-к-модему) · [Сборка](../docs/BUILD.md)

Версия для macOS 13+ на Apple Silicon. Подготовка проверяет Web, ADB и SSH,
устанавливает агент 2.8.0 и создаёт собственный SSH-ключ. VPN устанавливается
отдельной кнопкой. Публичная сборка не содержит ключей владельца или ключа
расшифровки firmware backup: backup-key suffix вводится отдельно и не сохраняется.

В 1.20.0 обновлены название, значок и синий интерфейс, добавлены русский и
английский языки. Каталог отображается списком и содержит только проверенные
htop и opkg; подписанный список обновляется с GitHub отдельно от программы.
Уже установленные приложения доступны для просмотра и удаления независимо от
каталога. Terminal открывает SSH-сеанс при входе в раздел и поясняет требование
opkg для установки пакетов. В настройках SSH доступны кнопки выбора файлов.

Подготовка, Launcher, Guest Wi-Fi VPN, диагностика и бэкапы сохраняют прежние
проверки. Полные образы eMMC доступны отдельно от бэкапов настроек;
восстановление требует проверенного образа того же устройства и подходящей
среды восстановления.

Штатная поддерживаемая прошивка — B31. Профиль B02 экспериментальный и требует
уже работающего root ADB по USB; это не подтверждает совместимость записи IMEI.
SSClash не включён в архив и пока не одобрен для установки через проверенный
каталог. Существующими установками можно управлять; встроенный установщик
использует официальный файл с закреплёнными размером и SHA-256.

Все ресурсы устанавливаются после проверок идентичности и целостности.
Исходники тестов используют синтетические данные; устройство при локальной
сборке и проверках не подключается.
