# ZTE U60Pro Manager 1.24.5 для macOS ARM64

## Кандидат build 46

Подготовка проверяет готовый SSH, root USB ADB, штатный USB debug через Web
и способ через бэкап. После неудачи способа проверяется следующий. Выбор зависит
от возможностей устройства и формата архива, включая ранние прошивки MU5250.
Известный платформенный ключ бэкапа проверяется автоматически; ручной
Backup-key suffix — необязательная замена.

Обычный SSH-доступ работает без агента, паролей Web, CID и совпадения с B31.
ADB используется для первоначальной подготовки SSH. Проверка SIM отдельно
распознаёт обычную карту; профилями можно управлять на съёмной eUICC.
Переключение с восстановлением радио пока использует проверенный путь B31.
[Изменения и границы проверки](../docs/RELEASE-1.24.5.md).

**«Проверить ключ бэкапа»** в параметрах первоначальной подготовки работает
через штатный Web без SSH/ADB. Она проверяет свежий архив без восстановления
и установки; результат для FLYMODEM B28 пока ожидается от устройства SashaRIP.
[Источники и исследование ключей](../docs/BACKUP-KEY-RESEARCH.md).

## Изменения в 1.24.0

- Первое действие — «Проверить устройство»: технический сбор через доступный
  USB ADB/SSH независимо от версии прошивки, root и наличия штатного Web API.
- Отдельные наблюдения и условия каждой функции; неполная привязка и пропуски
  видны в отчёте. ZIP содержит команды, результаты и контрольные суммы.
- Измеренная установка SSH и пассивного агента через уже работающий root USB
  без Web API; свежие проверки устройства и среды перед каждым этапом.
- На неизвестной прошивке агент `2.9.0-esim.1` работает в режиме диагностики.
  IMEI/eSIM и остальные аппаратные функции сохраняют отдельные проверки.

[Границы и проверки сборки](../docs/RELEASE-1.24.0.md).

## Ранее: изменения с 1.20.0 по 1.23.2

- **eSIM на физической eUICC.** Чтение всех профилей, загрузка по QR или по
  SM-DP+ Address и Activation Code, включение и удаление выключенного профиля.
  Проверенный путь — съёмная **9eSIM V0 в физическом SIM-слоте** на B31.
  Поддержка загрузки во встроенный чип eSIM не заявляется.
- **Переключение с перечитыванием SIM.** Агент сначала подтверждает изменение
  профиля и закрывает APDU-канал. Затем выполняет ограниченный цикл радио и
  питания физической SIM, проверяет READY и ICCID. Успех перечитывания SIM
  не означает, что модем уже зарегистрирован в сети оператора.
- **eSIM на экране модема.** Из программы устанавливается страница Launcher
  со списком и переключением профилей. Дополнительные страницы Info, VPN и eSIM
  можно выбирать и менять местами. Установка плиток не требует установки VPN.
- **Агент с eSIM и веб-панель.** Постоянная установка использует агент
  `2.7.0-esim.8`. Отдельная веб-панель агента также поддерживает eSIM; загрузке
  через неё нужен интернет модема. Настольная программа выполняет HTTPS на Mac,
  поэтому ей достаточно интернета компьютера.
- **Понятная диагностика.** Журнал показывает этапы, время, счётчики APDU/HTTPS
  и фиксированные причины ошибок. Коды активации, HTTP/APDU-содержимое, полные EID
  и ICCID в журнал не выводятся. Добавлено исследование доступных функций прошивки
  без изменения конфигурации.

## Работа с eSIM

Сначала проверьте SSH-подключение и прочитайте карту. Перед изменением профиля
программа сверяет карту и полный список с последним снимком. После загрузки
новый профиль остаётся выключенным; включение выполняется отдельным действием.
Для уже включённого профиля кнопка перечитывания SIM выполняет тот же проверяемый
цикл без повторной команды включения профиля.

Операция не повторяется автоматически после ошибки. Если состояние APDU-канала
неизвестно, программа просит перезагрузить модем перед новой попыткой; при
неготовности карты — подождать и обновить список. Если включение питания SIM
или радио не подтверждено, результат не отображается как успешный. Сбой питания
самого модема или принудительное завершение процесса не покрываются восстановлением.

## Подготовка и публичная сборка

Подготовка проверяет Web, ADB и SSH, создаёт собственный SSH-ключ и устанавливает
агент. VPN устанавливается отдельной кнопкой. Публичный архив **не содержит**
SSH-ключей владельца, сохранённых ключей хостов или device backups. Известный
платформенный суффикс входит в программу; персональный IMEI читается у модема.
**Backup-key suffix** позволяет ввести замену, которая не сохраняется. Ключ
используется только в способе через бэкап; работающий ADB и штатный USB debug
проверяются без расшифровки.

SSClash не включён в архив и пока не одобрен для установки через проверенный
каталог. Существующими установками можно управлять; отдельный установщик
загружает файл из официального релиза только по явному действию и проверяет
закреплённые размер и SHA-256. Его proprietary-лицензия не разрешает включать
бинарник SSClash в публичный ZIP этой программы.

Остальные функции сохраняются: подготовка SSH/агента, IMEI, Guest Wi-Fi VPN,
TTL, терминал, диагностика и резервные копии. Восстановление полного образа
требует проверенного образа того же устройства и подходящей среды восстановления.

## Локальная сборка и проверки

Выполняйте общий [процесс сборки](../docs/BUILD.md), чтобы сначала пересобрать
модемные компоненты, ресурсы и их pins. Затем `cd MacIMEI && ./build.sh` создаёт
`dist/ZTE U60Pro Manager.app`, ZIP `dist/ZTE-U60Pro-Manager-1.24.5-arm64.zip`
и `dist/build-manifest.json`. Приложение подписывается ad-hoc; это не notarization.

Тесты в `Tests/` используют синтетические данные. `tools/check_diagnostics.py`
собирает и запускает выбранные Swift-наборы без модема; eSIM TLS-тесты в
`../tools/esim-app/` используют временные сертификаты без сетевых запросов.
Соответствующие исходники агента, lpac и bridge и лицензии входят в eSIM-ресурсы.
Результаты проверки этой Mac-сборки не являются проверкой запуска Windows-версии.
