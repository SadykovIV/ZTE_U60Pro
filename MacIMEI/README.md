# ZTE IMEI Studio 1.19.0 для macOS ARM64

[Описание программы](../docs/APPLICATION.md) · [Требования к модему](../README.md#требования-к-модему) · [Сборка](../docs/BUILD.md)

Версия для macOS 13+ на Apple Silicon. Подготовка проверяет Web, ADB и SSH,
устанавливает агент 2.8.0 и создаёт собственный SSH-ключ. VPN устанавливается
отдельной кнопкой. Публичная сборка не содержит ключей владельца или ключа
расшифровки firmware backup: backup-key suffix вводится отдельно и не сохраняется.

В этой версии добавлены проверка каналов и паролей, ограниченная диагностика
через ADB, отдельное обновление разделов, редактор Launcher с предпросмотром,
выбором параметров, порядком и видом «плитки / список», настройка Guest Wi-Fi VPN,
каталог диагностических приложений, изолированный opkg и SSH terminal.
Полные образы eMMC доступны отдельно от бэкапов настроек; восстановление требует
проверенного образа того же устройства и подходящей среды восстановления.

Штатная поддерживаемая прошивка — B31. Профиль B02 экспериментальный и требует
уже работающего root ADB по USB; это не подтверждает совместимость записи IMEI.
SSClash не включён в архив: явная кнопка установки загружает закреплённый
официальный файл и проверяет размер и SHA-256.

Все ресурсы устанавливаются после проверок идентичности и целостности.
Исходники тестов используют синтетические данные; устройство при локальной
сборке и проверках не подключается.
