# Русский интерфейс экрана B31

Ревизия словаря: 20260924. Проверенный профиль: ZTE MU5250 / U60 Pro, CN_ZTE_MU5250V1.0.0B31.

English.ini и Chinese.ini подготовлены по ресурсам этого модема. Китайский пункт заменён русским; внутренние коды остаются en/cn. Русский словарь содержит 729 ключей: полностью вычитанный перевод, короткие подписи и обычные пробелы, поддерживаемые штатным шрифтом.

font.patch.json содержит только изменения центрального выбора шрифта. Приложение читает исходный исполняемый файл с подключённого модема, проверяет его SHA-256 и исходные байты каждого участка, применяет патч в памяти, затем проверяет итоговый SHA-256. Полный исполняемый файл модема в приложение не включён. Русский текст использует 85% исходного размера; английский и специальные цифровые шрифты не меняются.

install.sh устанавливает управляемую копию ресурсов в /data/zte-imei-screen-ru. service.sh подключает её перед запуском экранного интерфейса. На B31 overlay /etc монтируется после начала обработки списка служб, поэтому одного нового S47 недостаточно. Установщик добавляет проверяемый вызов в существующий скрипт запуска UI, сохраняя точный оригинал. Отключение возвращает этот скрипт, исходные ресурсы и английский язык; проверенные файлы остаются для повторного включения. Исходные файлы /usr и rc.local не изменяются.

Установка привязана к идентификатору подключённого модема и точным контрольным суммам B31. Другая прошивка или изменённые системные ресурсы требуют отдельной проверки совместимости. Сброс заводских настроек и обновление прошивки могут убрать службу или сделать перевод несовместимым; после них требуется проверка состояния в приложении.

Происхождение и проверки в исходном проекте: evidence/russian-ui-compact-copy-20260922, evidence/russian-ui-font-trial-20260922, evidence/russian-ui-persistent-20260922. Финальные контрольные суммы ресурсов — SHA256.json.
