# Русский интерфейс экрана B31 и FLY B28

Ревизия менеджера: 20261006; словаря: 20260924. Профили выбираются по точным исходным UI/INI/init, а не по названию радиопрошивки. Поддержаны ресурсы CN_ZTE_MU5250V1.0.0B31 и FLY_CN_MU5250V1.0.0B13 / BD_FLYMODEMMU5250V1.0.0B28.

English.ini и Chinese.ini подготовлены по ресурсам этого модема. Китайский пункт заменён русским; внутренние коды остаются en/cn. Русский словарь содержит 729 ключей: полностью вычитанный перевод, короткие подписи и обычные пробелы, поддерживаемые штатным шрифтом.

font.patch.json (B31) и font.patch.b28.json (FLY B28) содержат только изменения центрального выбора шрифта. Приложение читает исходный исполняемый файл с подключённого модема, проверяет его SHA-256 и исходные байты каждого участка, применяет патч в памяти, затем проверяет итоговый SHA-256. Полный исполняемый файл модема в приложение не включён. Русский текст использует 85% исходного размера; английский и специальные цифровые шрифты не меняются.

install.sh устанавливает управляемую копию ресурсов в /data/zte-imei-screen-ru. service.sh подключает её перед запуском экранного интерфейса. На B31 overlay /etc монтируется после начала обработки списка служб, поэтому одного нового S47 недостаточно. Установщик добавляет проверяемый вызов в существующий скрипт запуска UI, сохраняя точный оригинал. Отключение возвращает этот скрипт, исходные ресурсы и английский язык; проверенные файлы остаются для повторного включения. Исходные файлы /usr и rc.local не изменяются.

Установка привязана к проверенному сеансу root/Linux ARM64, CID и точным контрольным суммам UI, исходных словарей, init и шрифта с кириллицей ZTEZhengYuan.ttf. Неизвестные или смешанные ресурсы профилей отклоняются до изменения. Файлы шрифтов не устанавливаются и не меняются; иной пользовательский шрифт требует отдельной проверки метрик. Сброс заводских настроек и обновление прошивки могут убрать службу или сделать перевод несовместимым; после них требуется проверка состояния в приложении.
