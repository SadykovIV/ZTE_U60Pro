# Дополнительные приложения

SSClash-Go v6.4.1 не включён в публичный дистрибутив: его лицензия запрещает
перепубликацию исполняемого файла. После нажатия «Установить» программа загружает
официальный asset и проверяет размер 11010232, Linux ARM64 ELF и SHA-256
38ba859187c953d159cdd4f1ff397feb5f29116e0bfc7dc284c45b1a6766c770.

Источник: https://github.com/zerolabnet/SSClash-Go/releases/tag/v6.4.1
Полная лицензия сохранена рядом. Сценарии интеграции и удаления — собственный код.
Пароль задаёт владелец; удаление поддерживает только установки с нашим owner-marker
и сначала сохраняет архив приложения. Архив может содержать секреты.
