# Лицензии Windows-компонентов

Windows portable комплект содержит .NET runtime, Avalonia, SSH.NET и их
зависимости. Точные версии и исходные проекты указаны в `packages.json`;
оригинальные license/notice файлы сохранены рядом из NuGet-пакетов либо
официального upstream. В списке присутствуют и платформенные зависимости
восстановления проекта, которые могут не входить в конечный Windows EXE.

Лицензии Android ADB и Microsoft OpenSSH находятся в `../Tools`, а лицензии
компонентов модема — в соответствующих каталогах `Resources`. Лицензия
основного приложения не заменяет лицензии этих компонентов.
