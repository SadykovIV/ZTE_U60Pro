# ZTE U60Pro Manager 1.24.0 для Windows x64

Приложение на Avalonia/.NET 10 для ZTE MU5250 B31: обычное подключение SSH,
подготовка доступа, Launcher, VPN, TTL, каталог приложений, Terminal,
резервные копии и управление съёмной eUICC. На B02 подготовка требует уже
работающего root ADB; функции, привязанные к B31, ограничены.

## Подготовка доступа

Для предварительной подготовки введите адрес, пароль веб-интерфейса,
пароль агента и подключите USB-кабель с передачей данных. Программа проверяет
уже работающий root ADB; иначе последовательно проверяет штатное USB debug
(для прошивок, где он поддерживается) и метод B31 через проверенный бэкап.
Затем устанавливает агент и SSH и подключается по SSH.

**Backup-key suffix вашей прошивки** нужен только для расшифровки и проверки
бэкапа в ветке B31. Публичная сборка его не содержит. Значение вводится в скрытое
поле, не сохраняется в настройках или журнале и очищается вместе с другими
секретами после операции или смены страницы. Работающий ADB, штатный USB debug
и продолжение уже отправленного восстановления/перезагрузки суффикса не требуют.

Кнопка **«Принудительно включить ADB»** работает отдельно, в том числе при
подключённом SSH. Она предназначена для диагностики, не устанавливает агент и
не меняет ключи SSH. Если в проверенном бэкапе B31 уже есть строка автозапуска ADB,
но USB ADB отсутствует, выполняется одна штатная перезагрузка. Отправленные
переключение USB, восстановление и перезагрузка не повторяются автоматически:
**«Продолжить включение ADB»** сверяет тот же модем по сохранённому журналу.
Перед запуском закройте интерактивный терминал. На прошивках кроме точной B31
новое включение доступа требует галочки пропуска общей проверки; это не
разрешает восстановление B31 на другой прошивке и не снимает ограничения установщика.

ADB доступен для исследования прошивки; обычные функции приложения используют SSH.

Пароли, SSH-ключи и бэкапы остаются в `%LOCALAPPDATA%/ZTE IMEI Studio`.
Храните этот каталог как конфиденциальные данные. При неопределённом исходе
установки автоматической повторной отправки нет; сначала проверьте состояние.

## eSIM

Поддерживается **съёмная eUICC в физическом SIM-слоте 1 MU5250 B31**;
проверенная аппаратная комбинация — 9eSIM V0. Доступ к встроенной карте ZTE
через consumer RSP не подтверждён и этим интерфейсом не предоставляется.

Прочитайте профили, затем используйте один из вариантов:

- полный LPA-код или изображение с одним QR;
- отдельные поля SM-DP+ Address и Activation code (Matching ID).

Код подтверждения вводится отдельно, если его требует оператор. Загрузка
оставляет новый профиль отключённым. Удаление доступно только для отключённого
профиля и требует подтверждения. Активация или перечитывание активного профиля
прерывает мобильное соединение: агент закрывает канал карты, выключает радио,
один раз перезапускает питание SIM в слоте 1 и возвращает радио. Успех требует
готовности USIM, совпадения ICCID и свежего списка профилей. Регистрация в сети
проверяется отдельно. При неизвестном закрытии канала или восстановлении питания
программа предлагает перезагрузить модем; автоматического повтора изменения нет.

Desktop использует интернет компьютера и приватный SSH RPC. Веб-панель агента
использует интернет модема. HTTPS проверяет имя сервера, срок и цепочку сертификата;
к системному доверию добавлен закреплённый набор официальных production-корней GSMA.
Системное хранилище сертификатов не меняется. Журнал содержит этапы, время,
счётчики и фиксированные ошибки, без QR, Matching ID, подтверждения, полных
идентификаторов и содержимого APDU/HTTP. Секретные поля очищаются после отправки.

«Установить агент и веб-панель» устанавливает постоянный агент из того же
публичного пакета, что используется временным RPC. Панель размещается в закрытом
`/data/zte-dashboard-runtime`; права штатных каталогов не ослабляются.
Предыдущий публичный агент 2.8.0 распознаётся; старый VPN-контроллер допускается
только для чтения состояния перед обновлением.

## Страницы Launcher

В «Плитки на экране модема» можно выбрать «Информация», VPN и eSIM и изменить
порядок. «Применить выбор страниц» меняет настройку без перезапуска экрана;
если отключить все дополнительные страницы, остаются две штатные.
Несохранённые настройки информационных показателей сохраняются отдельно.
Кнопка установки страницы в eSIM добавляет её в конец текущего порядка,
если страницы ещё нет, и сохраняет остальные настройки. При отсутствии VPN
эта кнопка его не устанавливает. Повреждённый или небезопасный файл настроек
блокирует перезапись.

## Публичная сборка

Нужен .NET SDK 10. Получите зависимости и пересоберите ресурсы согласно корневому
README, затем синхронизируйте проверенные публичные ресурсы:

```sh
python3 Windows_x64/sync_public_resources.py
python3 Windows_x64/sync_public_resources.py --check
```

На Windows запустите `Windows_x64/build.cmd`; на macOS с PowerShell:

```sh
pwsh -NoProfile -File Windows_x64/build.ps1
```

Сборка использует закреплённый NuGet lock, отображение путей исходников,
проверяет PE x64 и точное совпадение ресурсов, создаёт portable ZIP и JSON
с SHA-256. Существующий выпуск не перезаписывается. Публичный пакет не включает
SSClash binary, пользовательский known_hosts или ключ бэкапа. SSClash при явной
установке загружается из закреплённого upstream-релиза с проверкой хеша.

Результаты находятся в `Windows_x64/dist/portable1.23.3/`,
`ZTE-U60Pro-Manager-1.23.3-Windows-x64-portable.zip` и
`windows-1.23.3-build-manifest.json`. Распакуйте весь ZIP; `Resources` должны
оставаться рядом с EXE. Дополнительная установка .NET не нужна.

## Границы проверки

Тесты используют синтетические данные, fake SSH и Avalonia.Headless на macOS.
Кросс-сборка и PE/ZIP-проверки не доказывают запуск на Windows OS: в текущем
окружении он не проверен. Аппаратные проверки общего агента на B31/9eSIM V0
относятся к отдельно зафиксированным сборкам; публичный rebuild имеет собственные
хеши. Скриншоты — previews с синтетическими данными.

Тестовые исходники: `tests/`, `research-tests/`, `card-recovery-tests/`,
`card-recovery-pages-tests/`, `esim-tests/`, `ui-smoke/`. Синтетические QR и
фиксированный каталог диагностических кодов включены в эти каталоги;
приватные отчёты и устройство для тестов не нужны.
