# ZTE IMEI Studio для Windows x64

В этой папке находятся исходники Windows-приложения и все файлы устройства,
которые входят в portable комплект. Интерфейс написан на Avalonia/.NET 10;
Windows выпуск включает среду .NET внутри приложения.

Для предварительной подготовки через Web нужен Backup-key suffix вашей
прошивки: владелец вводит его в отдельном защищённом поле. Суффикс не входит
в публичный код и не сохраняется в настройках или журнале.

SSClash-Go не включён в комплект из-за условий upstream-лицензии. Кнопка
«Скачать и установить» загружает закреплённый официальный релиз и проверяет
размер, архитектуру ARM64 и SHA-256. Остальные встроенные компоненты доступны
без дополнительной загрузки; установка пакетов через opkg требует сети.

В приложении доступны подготовка модема через Web и USB ADB, подключение по
SSH или ограниченному ADB, чтение и запись IMEI на проверенной B31, Launcher,
VPN, TTL, каталог приложений, изолированный opkg, интерактивный Terminal,
управление доступами и резервные копии. На B02 подготовка требует уже
работающего root ADB; действия, зависящие от схемы B31, заблокированы.
Изменение IMEI и установка компонентов на реальном модеме в рамках этой
Windows-сборки пока не проверялись.
Установка VPN сохраняет проверку штатного `flock`: встроенный контроллер VPN
закрепляет хэш firewall-скрипта и использует эту блокировку при применении
правил. Если в прошивке нет `flock`, установка VPN безопасно остановится;
адаптеры диагностических утилит и opkg в Windows-комплекте используют
отдельную атомарную блокировку и не зависят от штатного `flock`. После
аварийного завершения они сохраняют блокировку до ручной проверки состояния,
чтобы не повторить потенциально незавершённую установку.

## Сборка

Из Git checkout сначала выполните `python3 tools/fetch_dependencies.py` в корне
репозитория: бинарные зависимости хранятся в архиве релиза, проверяемом по
SHA-256. Для пересборки собственных компонентов модема используется корневая
система сборки; после неё `python3 Windows_x64/sync_public_resources.py`
переносит проверенные публичные агент, VPN, Launcher, панели и IMEI helpers в
Windows и обновляет закреплённые хэши C#. Скрипт не читает приватный проект.

На Windows x64 установите .NET SDK 10 и запустите `build.cmd` из этой папки.
Релиз проверен с SDK 10.0.107 и runtime 10.0.7. Первая сборка загружает
NuGet-пакеты Avalonia 11.3.12 и SSH.NET 2025.0.0; точные версии зависимостей
и их контрольные суммы закреплены в `src/packages.lock.json`. Скрипт
восстанавливает зависимости в locked mode, затем публикует без повторного restore.
Скрипт создаёт `dist/portable/ZTE IMEI Studio.exe`, копирует рядом `Resources`,
проверяет PE-архитектуру x64 и SHA-256 каждого ресурса, затем создаёт
`dist/ZTE-IMEI-Studio-1.19.0-Windows-x64-portable.zip`.
Рядом создаётся `dist/windows-build-manifest.json` с относительными именами,
размерами и SHA-256 EXE, ZIP и ресурсов; абсолютных локальных путей в нём нет.

На macOS с .NET SDK 10 можно выполнить кросс-сборку:

```sh
dotnet publish src/ZteImeiStudio.Windows.csproj -c Release -r win-x64 \
  --self-contained true -o dist/portable -p:NuGetAudit=false
```

Перед передачей такого комплекта проверьте EXE на Windows x64: macOS не может
запустить Windows-приложение. Для запуска на целевом ПК распакуйте весь ZIP и
откройте `ZTE IMEI Studio.exe`. Отдельная установка .NET не требуется. Файлы
`Resources` должны оставаться рядом с EXE.

## Структура

- `src/` — приложение, контракт сервиса, транспорт SSH/ADB и логика функций;
- `Resources/` — проверяемые файлы, которые передаются на модем, и Windows ADB;
- `build.ps1`, `build.cmd` — публикация и контроль готового комплекта;
- `dist/portable/` — распаковываемое приложение;
- `dist/*.zip` — архив для переноса на Windows ПК.

Приложение хранит локальные настройки, журнал и бэкапы в профиле пользователя
Windows (`%LOCALAPPDATA%/ZTE IMEI Studio`). Пароли не входят в журнал или
манифесты. Во время первой установки пароль агента кратковременно помещается
в локальный файл для передачи по ADB, затем файл удаляется; стартовый скрипт
с паролем остаётся на модеме. Папку профиля и резервные копии нужно хранить
как конфиденциальные данные.

Бэкап данных в меню «Устройство» включает `modemst1`, `modemst2`, `fsg`,
`persist`, `/data` и выбранную конфигурацию. Отдельная кнопка «Создать полный
образ» сохраняет пользовательскую область eMMC, включая GPT и системные
разделы, а также boot0/boot1. Оба снимка делаются с работающего модема и не
являются атомарными; полный образ доступен только на проверенной B31 и может
занимать несколько гигабайт. RPMB/OTP в него не входят. Автоматического
восстановления этих копий нет: приложение создаёт их и проверяет SHA-256.
Подключение ADB по USB может требовать драйвер устройства в Windows; сам
`adb.exe` и его DLL уже включены в `Resources/Tools`.
