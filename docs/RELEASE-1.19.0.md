# ZTE IMEI Studio 1.19.0 — изменения с v1.9.1

Сравнение с предыдущей опубликованной версией [v1.9.1](https://github.com/SadykovIV/ZTE_U60Pro/releases/tag/v1.9.1). В выпуск вошли накопленные доработки приложения 1.10–1.19 и первая самостоятельная сборка для Windows x64. ZTE Agent обновлён до **2.8.0**, VPN-контроллер — до **1.3.0**. [Сравнение исходников v1.9.1 → v1.19.0](https://github.com/SadykovIV/ZTE_U60Pro/compare/v1.9.1...v1.19.0).

## Windows x64

- Добавлено отдельное приложение на Avalonia/.NET 10: подготовка модема, SSH и ограниченный ADB, IMEI на проверенной B31, Launcher, VPN, TTL, приложения, opkg, Terminal, доступы и резервные копии.
- Portable-комплект включает среду .NET, Windows ADB и необходимые ресурсы. Для запуска распакуйте весь ZIP и оставьте папку `Resources` рядом с EXE; отдельно устанавливать .NET не требуется. Для USB ADB Windows может потребоваться драйвер модема.
- Все исходники, ресурсы, тесты и скрипты сборки Windows находятся в `Windows_x64`.
- Доступно создание и проверка полного образа eMMC. Автоматическое восстановление полного образа в Windows пока не реализовано.

## Подключение и подготовка модема

- «Подготовка модема» перенесена в начало меню, «О модеме» — в конец. Параметры подключения собраны в одной карточке; рядом с подготовкой и записью IMEI доступны подробные пояснения.
- Исправлена индикация подключения и доступность действий: проверенный SSH либо ограниченный ADB отображаются явно, сведения разделов загружаются после подключения. Обновление одного раздела больше не перечитывает остальные и не сбрасывает их черновики.
- Проверка отдельно показывает доступность SSH, USB ADB, агента и штатного Web. Для Web и агента различаются отсутствие сервиса и неверный пароль. Рабочее SSH-подключение сохраняется при повторной проверке паролей.
- Предварительная подготовка создаёт отсутствующие родительские каталоги `/data/local/tmp`; ошибки ADB показывают причину и код удалённой команды.
- Для известной польской B02 добавлена ограниченная подготовка SSH/агента через уже работающий root ADB и диагностика через ADB при отсутствии SSH. Это не подтверждение совместимости B02 со сменой IMEI или расширением экрана.

## Launcher и VPN

- Дополнительные страницы экрана теперь устанавливаются и обновляются из отдельного раздела **Launcher**, с подразделами «Информация о модеме» и «Управление VPN» и предпросмотром.
- Информационная страница поддерживает прокручиваемый список и сетку плиток. Можно выбрать и упорядочить до 12 показателей: загрузку CPU, сигнал, тип сети, активные несущие, температуры CPU и модема, RAM, `/data`, время работы, батарею, RSRQ и SINR.
- Состав, порядок и вид страницы сохраняются на модеме и меняются без переустановки компонентов. Отсутствующие и устаревшие значения обозначаются явно. ZTEDATA для установки страниц не перезаписывается.
- VPN-плитка показывает фактические имена гостевых сетей. Из Launcher можно явно сохранить имя сети и выбрать пароль основной сети, собственный пароль либо сохранение текущего. Изменение доступно при выключенном VPN Wi-Fi; существующая сеть автоматически не переименовывается.
- В меню VPN доступна отдельная кнопка установки/обновления компонентов, в том числе когда VPN ещё не установлен. Предварительная подготовка устанавливает агент и SSH.

## Приложения и Terminal

- Исправлено разделение «Установлено» и «Каталог»: отдельные карточки, короткие описания, фактическое состояние и действия установки/удаления. Неудачная проверка больше не считается отсутствием приложения.
- Добавлены htop, iperf3, mtr и tcpdump с индивидуальной установкой, удалением и откатом состава. Компоненты размещаются в `/data` с собственными библиотеками; системные библиотеки и сетевые настройки не подменяются.
- Добавлен экспериментальный адаптер настоящего opkg с отдельной базой и поколениями пакетов в `/data`. Поддерживаются проверка подписей индексов, редактирование источников и откат. Указана совместимая база: OpenWrt 23.05.4, `aarch64_cortex-a53`.
- **Terminal** предоставляет интерактивный SSH-сеанс с PTY, Ctrl+C, конвейерами и перенаправлениями. Команда `opkg` обращается к приватному адаптеру; `/bin/opkg` остаётся явным вызовом штатного менеджера.
- Устранена блокировка установки приложений из-за отсутствия системного `timeout`: используется собственный проверяемый ARM64-помощник. Ошибка другой недостающей команды теперь называет её точно.

## Полные образы и исправления бэкапа

- В macOS добавлены полные образы основной области eMMC и boot0/boot1, проверка, импорт/экспорт и возобновляемый процесс восстановления с отдельной проверкой условий записи.
- Исправлена ошибка `CAPTURE_SIZE`: размер переданного образа проверяется 64-битным счётчиком; SHA-256 сравнивается отдельно. Незавершённая копия не публикуется как готовая.
- Полное восстановление macOS требует отдельно загруженной среды восстановления; её образ и автоматическая загрузка в неё не входят в комплект. Запись поверх работающего модема запрещена. Снимки работающей системы не атомарны; RPMB/OTP не копируются.

## Проверки и границы поддержки

Windows-комплект собран для x64, проверены структура PE, целостность архива и встроенных ресурсов. Синтетические тесты охватывают подготовку/архивы, IMEI-транзакции, прерванные операции и проверку полного образа; Avalonia-тест открывает 8 страниц и 18 подразделов. **Запуск на настоящей Windows и установка компонентов на физический модем из Windows пока не проверены.**

Для публичной macOS-сборки выполнены локальные тесты транспорта, Launcher, VPN-настроек, opkg, установщиков и резервных копий; проверены Rust-компоненты, веб-панель и подпись приложения. Новая публичная сборка после обезличивания не проходила повторную установку на физический модем. Полное восстановление eMMC и работа на других прошивках не подтверждены этими тестами. B31 остаётся основной проверенной конфигурацией; ограничения конкретных операций сохраняются при отключении общей проверки прошивки. opkg остаётся экспериментальным.

Для применения новой VPN-плитки обновите компоненты VPN из новой версии программы. Настройки имени и пароля меняются только после явного сохранения.


Windows VPN-установщик пока требует штатную команду `flock`. Диагностические приложения и opkg в Windows используют отдельную атомарную блокировку. Редактирование URL источника opkg не добавляет новый ключ доверия: индексы должны проходить проверку подписи.

## Файлы выпуска

- `ZTE-IMEI-Studio-1.19.0-macOS-arm64.zip` — macOS 13+ / Apple Silicon; подпись ad-hoc, без нотарификации.
- `ZTE-IMEI-Studio-1.19.0-Windows-x64-portable.zip` — самодостаточная Windows x64-сборка. Распакуйте весь архив. EXE не подписан сертификатом.
- `ZTE-Agent-2.8.0-aarch64-linux-musl.tar.gz` — агент, панель, лицензии и контрольные суммы; отдельный ELF доступен рядом.
- `Build-dependencies-1.19.0.tar.gz` — закреплённые ресурсы для сборки из публичных исходников.
- `Third-party-sources-1.19.0.tar.gz` — соответствующие исходники распространяемых компонентов и рецепты OpenWrt.
- `SHA256SUMS` и манифесты — размеры, версии и SHA-256 файлов.

Ключи владельца, ключ расшифровки бэкапа прошивки, бэкапы, рабочие VPN-профили, прошивка ZTE и исполняемый файл SSClash в публикацию не входят. Для SSClash используется явная загрузка официальной версии с проверкой SHA-256.
