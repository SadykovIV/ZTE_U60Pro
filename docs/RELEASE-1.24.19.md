# 1.24.19 — адаптация HK B04

Локальная сборка для macOS ARM64 и Windows x64. Агент 2.9.0-esim.9.

## Прошивка и найденные причины

Предоставлены два архива от 13 октября 2026 года, собранные Windows 1.24.14.
Firmware: `XCBZ_HK_MU5250V1.0.0B04`.
Inner: `BD_XCBZHKMU5250V1.0.0B04`.

В этой системе отсутствует `/firmware/image/modem.b16`. Root SSH и агент уже
работают; старые проверки файла останавливали независимые операции. Экранный
ELF отличается от B31, хотя языковые файлы и шрифты совпадают. В диагностике
также есть незавершённая подготовка; её состояние требуется проверить отдельно.

## Изменения

- Чтение идентичности компонентов допускает наблюдаемое отсутствие modem.b16.
  Совместимость каждой операции проверяется по её собственным зависимостям.
- Чтение пары IMEI через DIAG/API отделено от допуска записи NV. Перед чтением
  проверяется diag-router, после — неизменность устройства и загрузки.
- Добавлены профили русификации и Launcher по точным файлам HK B04.
- VPN и TTL используют измеренный профиль B04: штатный mdm, diag-router,
  сетевой скрипт и компоненты IPA. При загрузке системы нет зависимости от
  готовности штатного Web RPC.
- Подготовка умеет продолжать работу через независимо проверенный root USB ADB,
  если авторизация Web прошла, но его device_info имеет неподдерживаемый ответ.
  Ошибки пароля и несовпадение устройства по-прежнему обрабатываются отдельно.
- Переключение ADB учитывает измеренную USB/configfs-конфигурацию B04.
- Диагностический ZIP включает обезличенное состояние незавершённых установок.
- Сохранены профили B31/B28 и совместимость агента с ранее выпущенными
  менеджерами TTL и VPN.

## Границы проверки

B04 находится у владельца. Локальные тесты, проверка присланных бинарников и
сборка не заменяют запуск на его модеме. В частности, VPN-интернет с клиента,
TTL реальных пакетов, изображение на экране и ADB после перезагрузки должен
подтвердить владелец.

Смена IMEI/NV, системные образы и радиоцикл eSIM для B04 не объявляются
адаптированными этим выпуском. Для них недостаточно пассивного архива.
Чтение eSIM требует физическую eUICC и доступный QMI/APDU; наличие обычной SIM
или программных модулей eSIM этого не подтверждает. Встроенная eSIM ZTE не
получает поддержку установки собственных профилей.

## Проверка владельцем

1. Распаковать Windows ZIP полностью в отдельную папку; не запускать EXE из
   окна архиватора. Resources должна находиться рядом с EXE.
2. Подключиться по уже работающему SSH. Повторная подготовка для этого не нужна.
3. Обновить агент и веб-панель, затем отдельно установить нужные компоненты:
   русификацию, Launcher, TTL, VPN. Обновление программы не обновляет модем.
4. Проверить каждую операцию отдельно. Для VPN включить WiFi-VPN и проверить
   интернет с подключённого клиента; для TTL проверить фактические пакеты.
5. При ошибке сразу собрать «Логи и журналы», оставив проблемный компонент
   в том состоянии, в котором произошёл отказ. Для RECOVERY_PENDING сохранить
   локальные данные программы; не удалять вручную active, lock и журналы.
