# Ключи бэкапов MU5250/U60 Pro

## Откуда взят ключ B31

Суффикс не генерировался. Он опубликован исследователем iangcarroll в
[GitHub issue #8, комментарий от 23 августа 2026](https://github.com/jesther-ai/open-u60-pro/issues/8#issuecomment-5386189931).
Первая найденная локальная запись ссылается на этот комментарий 21 сентября,
до расшифровки нашего исходного бэкапа. Найденное значение совпадает с локально
проверенным. Полный пароль нашего веб-бэкапа — IMEI выбранного устройства
и этот суффикс без разделителя.

Ключ проверен на исходном бэкапе CN B31: расшифрованные байты совпали с
сохранённым оригиналом, gzip/tar и внутренний MD5 корректны, внутри 174 записи.
Это доказательство для этого бэкапа, а не всех моделей и версий.

## Что известно о других версиях

| Прошивка или модель | Результат |
| --- | --- |
| CN_ZTE_MU5250V1.0.0B31 / BD_CNMU5250V1.0.0B31 | Ключ проверен на исходном бэкапе |
| FLY_CN_MU5250V1.0.0B13 / BD_FLYMODEMMU5250V1.0.0B28 | Точная пара присутствует в отчёте SashaRIP; исходного зашифрованного бэкапа там нет, ключ пока не подтверждён |
| CN B01, B02, B27, B32 | Отдельного проверенного ключа для этих версий в исследованных источниках не найдено |
| MU5252, версия не указана | В исходном комментарии опубликован тот же суффикс; доказательства по конкретной версии нет |

Нового подтверждённого суффикса, отличающегося от B31, в этом исследовании
не установлено. Тестовая кнопка программы проверяет известный кандидат на
свежем архиве, чтобы подтвердить или опровергнуть его применимость.

## Может ли ключ формироваться на устройстве

Да, для MU5250 описан отдельный механизм: процесс zte_topsw_mc получает
зашифрованный back_restore_enckey из UCI, вызывает MBB_decryption из libztecrypto.so
и добавляет IMEI. Автор описывает получение внутреннего ключа AES из факторов
устройства. [Первичный разбор механизма](https://github.com/amenekowo/mu5250_tweaking/blob/bd38bbbf470eb7cd1a9849397b672670f45810d9/docs/config-backup-crypto.md).

В этом разборе точная прошивка и расшифрованный суффикс не опубликованы.
Применимость к FLYMODEM B28 и равенство результата нашему суффиксу не проверены.
Строка версии сама по себе не позволяет вычислить ключ. Начальная проверка
в программе проверяет готовый кандидат, а MBB_decryption не выполняет.
Если кандидат не подходит, следующим исследованием станет реальный путь
backup этой прошивки и его материалы ключа. Автоматического восстановления
с непроверенным ключом нет.
