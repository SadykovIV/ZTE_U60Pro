# 1.24.7 — установка компонентов после сброса

macOS **1.24.7 build 48**, Windows **1.24.7.0**, агент **2.9.0-esim.4**.

## Изменения

- Если сброс удалил службы из `/etc`, но сохранил проверенные компоненты в `/data`, программа восстанавливает их запуск. Это исправляет остановку установки агента, VPN и дополнительных страниц.
- Обновление VPN распознаёт возвращённый штатный сценарий сети. Старое состояние настройки архивируется; профили и их данные сохраняются. Программа не переносит прежние настройки сети поверх настроек после сброса.
- Проверка компонентов учитывает службу VPN, ссылки автозапуска и состояние сценария сети. Установка восстанавливает недостающие компоненты и проверяет результат.
- Агент можно установить при отсутствующем бинарнике и готовом запускающем скрипте. Неудачный запуск возвращает первоначальное отсутствие файла.
- Ошибки обновления VPN показывают конкретную причину. Подробности команды остаются в журнале.
- В подготовке появилась очистка компонентов и данных нашей программы с резервной копией. Значок **ⓘ** рядом с флажком объясняет состав очистки и её назначение. Флажок выключен по умолчанию.

- Скрипт очистки передаётся через стандартный ввод SSH, чтобы сервер модема не разрывал соединение из-за длинной строки команды. Очистку можно продолжить отдельно от подготовки или отменить до удаления.

[Чистая подготовка и ограничения](PREPARATION-1.24.7.md).

## Проверки

Результаты проверок на модеме и контрольные суммы готовых пакетов сохраняются в `verification-summary.json` рядом с ZIP в `dist/1.24.7`. Проверки общих скриптов и Windows-кода на Mac не подтверждают нативную работу на Windows или подготовку B28.

Управление eSIM требует **физическую eUICC в SIM-слоте**. Встроенная eSIM ZTE этим компонентом не поддерживается.
