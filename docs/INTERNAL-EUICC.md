# 1.28 Internal eUICC

Этот вариант предназначен для ZTE U60 Pro / MU5250, в котором штатная впаянная
eSIM заменена настоящей eUICC. Управление остаётся в существующем разделе
**eSIM** приложения и веб-панели. Физический SIM-слот можно использовать
для другой карты через обычный выбор SIM в настройках модема.

Программа **1.28**, macOS build **70**, Windows FileVersion **1.28.0.0**;
комплектный агент **2.10.0-internal.1**. База — стандартный проект 1.27.2,
HEAD `752de93cce9380ae067cf05a7bbc03f2e37b3162`. Основная рабочая копия
и предыдущие комплекты сохраняются отдельно.

## Что требуется

- Вместо оригинальной eSIM ZTE установлена настоящая eUICC с приложением
  ISD-R. Марка и содержимое карты не предполагаются заранее: агент читает
  EID и полный список профилей, включая допустимый пустой список.
- Модем доступен приложению по настроенному SSH. Настольное приложение
  временно запускает свой закреплённый агент для операций eSIM; постоянная
  установка агента для этих операций не нужна. Для веб-панели и страницы
  модема устанавливается соответствующий постоянный вариант Internal eUICC.
- Для загрузки профиля у компьютера или модема есть интернет в зависимости
  от выбранного клиента. Уже установленный профиль можно переключать без
  загрузки с сервера оператора.

Оригинальная eSIM ZTE этим вариантом не разблокируется. Изменённая распайка
ещё не проверена на устройстве; прежние результаты со съёмной 9eSIM не
подтверждают электрическую совместимость или работу заменённой карты.

## Использование существующего меню

1. Откройте приложение **Internal eUICC** и настройте подключение по SSH.
   У альтернативы отдельное хранилище настроек, поэтому в существующих
   настройках подключения вручную выберите ключ ранее подготовленного модема.
   Ключ из стандартной программы автоматически не копируется. Для веб-панели
   или страницы eSIM на экране сначала установите/обновите комплектный
   **Internal agent** в разделе **«Агент»** альтернативного приложения.
   Сохраните прежний комплект для возврата к стандартной версии.
2. Откройте **eSIM → Проверить карту и профили**. Управление разрешается после
   свежего чтения EID и профилей с подтверждённым завершением сеанса.
3. Загружайте профили через прежнюю QR/LPA-форму. Новый профиль сохраняется
   выключенным. Переименование доступно в веб-панели; удаляется только
   выключенный профиль. Эти операции не меняют выбранную SIM для сети.
4. Перед **включением профиля** или перечитыванием уже активного профиля
   откройте существующее меню выбора **SIM** и выберите **eSIM** как карту
   для мобильной связи. Агент проверяет этот выбор перед изменением профиля
   и повторно перед изменением радио. Другой корректно прочитанный выбор
   возвращает `esim_slot_not_selected`. Нечитаемое или некорректное значение
   возвращает `radio_read_failed`. Переключать SIM автоматически агент не будет.
5. Для связи через другую карту выберите физическую SIM штатным способом.
   Карта в физическом слоте не становится целью управления профилями.
6. Для меню eSIM на экране сначала установите/обновите комплектный
   **Internal agent** в разделе **«Агент»**, затем в разделе **eSIM** нажмите
   **«Установить / обновить страницу eSIM»** (на Windows —
   **«Установить / обновить страницу eSIM на модеме»**). Эта кнопка обновляет
   **Launcher**, но сама не обновляет агент: она проверяет уже установленный
   комплектный бинарник. Обновление одного агента также не обновляет Launcher.
   Новый Launcher и старый агент, как и старый Launcher
   с новым агентом, несовместимы; операция отклоняется вместо обращения
   к другому слоту. На точном поддерживаемом наборе B31 этот же Launcher
   исправляет название сети на главном экране и в сведениях: использует
   текущее имя сети из SDK вместо прежней китайской метки.

Не меняйте выбор SIM в штатном интерфейсе параллельно незавершённой
операции eSIM: агент повторно проверяет выбор, но не блокирует чужой интерфейс.

При потере связи сначала перечитайте состояние. Не повторяйте загрузку
вслепую: операторский код мог уже использоваться. Готовность USIM после
операции отдельно от регистрации в сети и доступности мобильного интернета.

## Два слота

| Карта | Назначение в этом варианте |
| --- | --- |
| eUICC вместо штатной впаянной eSIM | Цель существующего меню eSIM: QMI physical slot **2**, logical slot **2** |
| Карта в физическом SIM-разъёме | Обычная SIM для связи через штатный выбор; меню Internal eUICC её не изменяет |

Чтение, загрузка, переименование и удаление выключенного профиля обращаются
к внутренней карте независимо от штатного выбора SIM для сети. Включение
профиля требует уже выбранной eSIM, поскольку последующее восстановление
использует общее состояние радио модема. Это не обещание двух одновременно
активных мобильных подключений.

Номер маршрута основан на сохранённых данных B31 с выбранной eSIM.
Каждая операция проверяет текущую карту и ожидаемый маршрут. Автоматического
переназначения слотов, поиска карты в другом слоте или перехода к slot 1 при
ошибке нет. Неподтверждённая схема заканчивается отказом.

## Целостность комплекта и границы проверки

Локальный комплект сохраняется отдельно в `Releases/Local/1.28-internal-euicc`;
он не опубликован на GitHub.

Раздельное хранилище относится к приложениям на компьютере. На модеме
постоянный Internal eUICC заменяет прежний агент в том же `/data/zte-agent`
и использует существующий запуск службы и соответствующую веб-панель.
Две постоянные версии рядом не устанавливаются. Настольные операции eSIM
используют временно размещённый комплектный агент по SSH и не зависят
от наличия постоянного агента.

Launcher этого варианта обращается к агенту только через отдельную команду
`--esim-launcher-internal`. Старый и новый протоколы нельзя смешивать.

Веб-панель требует capability target `internal-euicc-slot2`; обычный старый
агент не считается подходящим. Настольный комплект содержит закреплённые
агент, runtime и соответствующие SHA-256. После изменения исходников цепочка
пересобирается, а готовые файлы проверяются по манифестам.

Во время подготовки выполнена аутентифицированная диагностика B31 по SSH
только для чтения: сеть сообщает T2/Tele2, оба признака выбора SIM равны 2,
проверены хэши UI/SDK, а прежняя метка `Operator2` равна CUCC. Новая сборка
на устройство не устанавливалась; исправление отображения не развёртывалось,
снимков исправленного физического экрана нет. Не
подтверждены на заменённой карте чтение EID/профилей, загрузка, удаление,
переименование, включение и восстановление мобильной связи. Локальные тесты
маршрута и отказов не заменяют эти проверки. Нативный запуск Windows также
нужно отличать от сборки Windows на macOS.
