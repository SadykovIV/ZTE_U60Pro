# Имя сети на штатном экране B31

> Дополнение 01.11.2026: исправление установлено на модем и проверено
> реальными кадрами экрана до/после перезагрузки.
> [Аппаратный отчёт](INTERNAL-EUICC-LIVE-20261101.md).

На фотографии владельца главный экран показывает `中国联通5G` над `eSIM`.
Чтение текущего состояния B31 показывает имя сети T2/Tele2 и отдельно старую
метку `Operator2=CUCC`. Вариант 1.28 исправляет источник отображаемого имени
через Launcher. Он не переименовывает профиль на eUICC и не меняет оператора
или выбранную SIM.

## Что прочитано на устройстве

Аутентифицированное SSH-чтение выполнено с проверкой ранее доверенного ключа
сервера. Временный alias сохранял строгую проверку; постоянное хранилище доверия
не изменялось. Для этой диагностики новая сборка не устанавливалась, APDU
и изменения профилей не выполнялись.

Обезличенный локальный снимок рабочей копии:
`.build/internal-euicc/network-name-readonly.json`.
Его SHA-256: `ab5c43183591f23dec8da2a0023e81023d29d5f54362e2e4801b062429b9b5af`.
Снимок не содержит адреса устройства, IMEI/EID/ICCID, ключей или паролей.

| Поле | Прочитанное значение |
| --- | --- |
| `integrate_version` | `CN_ZTE_MU5250V1.0.0B31` |
| `wa_inner_version` | `BD_CNMU5250V1.0.0B31` |
| `network_provider` | `T2` |
| `network_provider_fullname` | `Tele2` |
| `network_type` | `ENDC` |
| `rmcc` / `rmnc` | `250` / `20` |
| `get_sim_info.current_sim_slot` | `2` |
| `zte_get_current_slot_info.current_sim_slot` | `2` |

| `/usr/lib/libzte_SDKowrt.so` | `2433d902270b787373acc9d56d776fbd002e349a023d6fd999b19230c4e2c4d7` |

`eSIM` обозначает выбранную позицию SIM. Имя зарегистрированной сети —
отдельное поле; имя профиля и сохранённая метка `Operator2` ему не равнозначны.

## Причина в штатном UI

Статический разбор B31 выявил ранний возврат в `getNetworkProvider` главного
экрана по адресу `0x4c5248`: путь встроенной eSIM использует `ChineseOperator2`,
где значение CUCC превращается в фиксированное китайское название в UTF-32.
Поэтому этот путь может закончиться раньше чтения действительного сетевого
имени. Сохранённое `Operator2=CUCC` и присланная фотография согласуются с этим
механизмом; они не означают регистрацию в китайской сети.

## Коррекция отображения в Launcher

Launcher заменяет только callbacks получения имени оператора главного экрана
и страницы состояния. Источник — уже кешированные поля штатного SDK:
сначала `network_provider_fullname`, затем `network_provider`. В текущем
прочитанном состоянии это `Tele2`, затем резервное `T2`.

Преобразование UTF-8 в UTF-32 ограничивает результат 96 байтами UTF-8 и
60 Unicode-символами; усечение отмечается `...`. Некорректная кодировка,
управляющие и bidi-символы делают значение недопустимым. Пустое или ошибочное
полное имя позволяет
попробовать короткое; если оба недоступны, выводится тире. Возврата к
`Operator2`, IMSI, ICCID или выдуманному имени нет. Штатная логика отсутствия
сети и добавления технологии связи остаётся у вызывающего UI.

Новая логика включается только для точного SDK, указанного выше, и одного
из двух UI B31: текущего русского `16eb92…afa4` либо исходного
`e3914e78a8488cb736770f0ac9fb8ce10e0e5222fa50285f08e9e8be90d7f1e9`.
Кроме полных хэшей, проверяются ожидаемые указатели callbacks и инструкции
начала функций. Другие прошивки этот B31-адаптер имени не получают.
Неизвестный SDK сохраняет штатное отображение имени; остальные функции
Launcher продолжают использовать собственные проверки совместимости.

В этой реализации не отправляются команды записи SIM или UCI и не запускается
перерегистрация сети. Коррекция работает в памяти UI через расширение Launcher;
она не заменяет штатный файл UI или SDK. Состояние сети в кеше SDK может
обновляться с задержкой — исправление не делает его мгновенным измерением.

## Как применить и что ещё не проверено

В альтернативном приложении **1.28 Internal eUICC** сначала установите/обновите
комплектный **Internal agent** в разделе **«Агент»**. Затем откройте **eSIM**
и нажмите **«Установить / обновить страницу eSIM»** (на Windows —
**«Установить / обновить страницу eSIM на модеме»**). Вторая кнопка обновляет
**Launcher** и проверяет уже установленный комплектный агент, но сама его
не обновляет. Обновление одного агента также не заменяет Launcher.
Смешанные старые/новые пары отклоняются отдельной командой
`--esim-launcher-internal`.

На момент подготовки этого документа новый Launcher и исправление
отображения не установлены на модем. Снимков исправленного физического экрана нет.
Исправленная надпись на физическом экране, поведение после потери сети,
смены SIM, перезагрузки или смены оператора ещё не проверены. Прочитанные
T2/Tele2 и хэши — аппаратная диагностика прежнего состояния; тесты новой
коррекции и её сборка фиксируются отдельно в `VERIFICATION.json`.
