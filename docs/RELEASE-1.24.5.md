# 1.24.5 — подготовка разных прошивок

macOS **1.24.5 build 46**, Windows **1.24.5.0**, агент **2.9.0-esim.4**.

## Изменения

- Подготовка проверяет готовый SSH, root USB ADB, штатный USB debug через Web
  и способ через бэкап. После отказа способа проверяется следующий. Ранние
  прошивки MU5250 проходят ту же последовательность без галочки пропуска проверки.
- Установка SSH проверяет фактическую Linux ARM64-среду; название прошивки
  и совпадение с B31/B02 не ограничивают этот этап.
- Известный ключ бэкапа включён в программу и проверяется на скачанном архиве.
  Ручной Backup-key suffix необязателен; неверная замена не подменяется автоматически.
- «Проверить ключ бэкапа» проверяет ключ и формат через штатный Web без
  восстановления настроек, включения ADB и установки компонентов.
- Перед восстановлением проверяется штатный USB-блок rc.local. Исправлено
  сохранение журнала при переходе от восстановления к установке SSH на macOS.
- Все обычные операции используют SSH. Единая диагностика находится в
  «Подготовка модема → Диагностика», параметры каналов — в настройках подключения.
  Журнал действий остаётся на прежнем месте и включается в диагностический экспорт.
- Обычная SIM распознаётся отдельно. Управление eSIM использует физическую
  eUICC в SIM-слоте; встроенная eSIM ZTE не поддерживается этим компонентом.

## Проверки

Логика этой версии проверена в кандидате 1.24.4 build 45: macOS **105/20/38/6**,
Windows **224/170 — PASS**, исходный зашифрованный B31-бэкап PASS. После смены версии
пакеты пересобраны; проверяются metadata, исходники, ресурсы и локализация.
Проверка дисплея macOS отдельно исправляет надпись B31 до определения устройства.
Полный новый Web/restore/install-цикл после сброса, FLYMODEM B28 на устройстве
и нативный запуск Windows пока не подтверждены.
