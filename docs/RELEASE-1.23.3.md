# 1.23.3 — изменения относительно 1.23.2

- **ADB:** исправлено обнаружение USB на Windows; добавлены последовательная проверка методов ранних прошивок/B31 и понятные причины недоступности.
- **Подготовка:** Web → ADB → агент и SSH. Обычное подключение использует SSH; отдельная кнопка **«Принудительно включить ADB»** работает и на уже подготовленном модеме.
- **Продолжение после обрыва:** отдельный журнал диагностического ADB, проверка результата без повторной отправки restore/reboot, блокировка пересекающихся изменений.
- **Terminal:** исправлены обрезанные нижние строки и прокрутка; в Windows блокировка других изменений сохраняется на всё время сеанса.
- Подробная справка по командам и сценариям подготовки на русском и английском.

macOS ARM64 / Windows x64 portable. Агент **2.7.0-esim.8** и модемные компоненты не изменены.
[Методы получения ADB и ограничения прошивок](ADB-PREPARATION.md).

На реальном B31 отдельно проверены включение USB ADB загрузочной строкой и возврат
исходного состояния. Это не полный повтор подготовки заводского модема через Web.
Новый диагностический сценарий и продолжение после обрыва проверены локальными тестами;
полный Web-цикл новой кнопки на устройстве не повторялся. Ранние прошивки на устройстве
не проверялись. Windows проверен сборкой x64 и тестами Avalonia на Mac; запуск EXE
в Windows не проверен. Публичные ZIP проходят отдельную проверку целостности и состава.

Ограничения eSIM прежние: нужна съёмная физическая eUICC; встроенная eSIM ZTE не поддерживается.
