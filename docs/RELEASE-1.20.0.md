# ZTE U60Pro Manager 1.20.0

Изменения относительно [1.19.0](https://github.com/SadykovIV/ZTE_U60Pro/releases/tag/v1.19.0):

- Новое название, значок и единый синий стиль macOS и Windows.
- Переключение Русский / English, «О программе» и выбор SSH-файлов.
- Компактный проверенный каталог htop/opkg с отдельным подписанным обновлением с GitHub.
- Автоматическое открытие SSH Terminal и пояснение по установке opkg.

Существующие настройки сохраняются. Агент остаётся версии 2.8.0. Сборки и локальные тесты проверены; запуск на физической Windows пока не проверен.
