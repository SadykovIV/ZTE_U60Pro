# 1.24.2 — доступ к VPN после предыдущей установки

macOS и Windows распознают проверенный VPN-контроллер из выпуска агента
2.7.0-esim.8 при чтении состояния. Раньше этот компонент уже поддерживался
процедурой обновления, но отсутствовал в списке разрешённых компонентов для
чтения. Раздел VPN поэтому показывал ошибку проверки ответа, а macOS также
не могла перейти к обновлению через предварительное чтение состояния.

Предыдущая сборка агента с подтверждённой контрольной суммой теперь
распознаётся при отдельном обновлении компонентов. Установщик сохраняет
прежний агент и проверяет устройство, файлы и условия восстановления.
Изменение VPN через старый контроллер требует обновления компонентов.
Неизвестный контроллер и небезопасная структура каталогов дают отдельную
понятную ошибку до разбора JSON.

Агент сохраняет версию 2.9.0-esim.1, спецификация исследования — 7.
Исправления ADB из 1.24.1 включены. Архивы исследования Windows 1.23.2
могут содержать пропущенные проверки из-за обработки окончаний строк ADB.
Для такого архива нужно повторить «Проверить устройство» в новой версии;
неполный старый отчёт не подтверждает несовместимость прошивки.

## Проверки и границы

Регрессии проверяют чтение известного предыдущего контроллера, отказ
изменения через него, ошибки неизвестного компонента и сохранение проверок
перед обновлением. Архивы сборок проверяются по исходникам, ресурсам и
контрольным суммам. Аппаратный запуск Windows требует отдельной проверки
на Windows.

На подключённом модеме исправленный клиент дважды прочитал состояние VPN.
Свежие данные USB и SSH подтвердили устройство и загрузку до и после чтения.
Контрольные суммы агента, VPN-профилей и сетевых файлов сохранились.
Обновление компонентов на модеме в этой проверке не выполнялось.
