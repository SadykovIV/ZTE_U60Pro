# 1.24.6 — подготовка разных прошивок и восстановление подключения

macOS **1.24.6 build 47**, Windows **1.24.6.0**, агент **2.9.0-esim.4**.

## Исправления 1.24.6

- Пароли штатного Web и агента, ручной ключ бэкапа сохраняются в памяти окна между действиями. Проверка ключа, обновление страницы и ошибка подготовки больше не очищают их. Смена устройства, порта или контекста ключей и закрытие приложения очищают значения. Записи на диск нет.
- «Обновить» заново проверяет SSH выбранного устройства. Ошибка убирает устаревший статус доступного SSH; подготовку можно повторить без перезапуска приложения. Журнал отправленных действий сохраняется.
- Установщик работает из приватного `/data/zte-imei-studio`, поэтому штатные каталоги `/data/bin` и `/data/local/tmp` с правами 777 не блокируют подготовку. Их права остаются прежними.
- Перед проверкой запуска бинарники, переданные с правами 600, получают право исполнения после проверки хэша и формата. Это исправляет ошибку `DROPBEAR_ABI`, найденную при разборе отчёта SashaRIP.
- SSH запускается с явным `-p 2222`. Успех требует подтверждённого слушателя приложения на этом порту, включая IPv4/IPv6. Чужой слушатель не останавливается.
- При обычной подготовке неактивный старый агент сохраняется в снимке и заменяется текущей проверенной сборкой. Корректный файл запуска и пароль сохраняются. Если файла запуска нет, используется пароль, введённый при подготовке. Для замены работающего агента доступны установка агента по SSH и отдельный принудительный режим подготовки.
- Продолжение ранее отправленного восстановления использует уже готовый root USB ADB без повторного входа в Web и без нового restore. Уже отправленная установка продолжает свой сохранённый путь и сценарий.
- В диагностическом экспорте Windows версия приложения сохраняется как версия; прежняя очистка ошибочно принимала `1.24.5.0` за IP-адрес.

- В параметрах первоначальной подготовки появился принудительный режим. До замены сохраняются текущие компоненты и контрольные суммы; агент получает введённый пароль. SSH использует порт 2222 и приватные пути; проверенные ключи и работающий слушатель сохраняются. Незавершённая операция использует сохранённый режим, даже если изменить флажок.
- После успешного завершения принудительной установки очищаются только подтверждённые временные каталоги завершённых установок. Каталоги без признака отправленной установки могут принадлежать другой загрузке и сохраняются. Чужие файлы, неизвестное состояние, резервные копии и журналы не удаляются. При ошибке только подтверждённый откат разрешает новую попытку отдельным действием пользователя.
- Чтение VPN распознаёт контроллер из опубликованной 1.24.4 build 42; его можно обновить без ошибочного сообщения о неизвестной сборке.

## Общая подготовка

Программа проверяет **SSH → root USB ADB → штатный USB debug через Web → способ через бэкап**. После отказа способа проверяется следующий. Установка SSH проверяет фактическую Linux ARM64-среду, инструменты и переданные файлы. Название прошивки не заменяет проверку совместимости.

Известный ключ бэкапа включён в программу и проверяется на скачанном архиве. Ручной ключ необязателен. «Проверить ключ бэкапа» читает и проверяет архив через штатный Web без восстановления настроек и установки компонентов. Проверка штатного USB-блока перед записью выполняется отдельно.

Все обычные операции используют SSH. Диагностика находится в «Подготовка модема → Диагностика», параметры каналов — в настройках подключения. Журнал действий остаётся на прежнем месте и включается в общий диагностический архив.

Управление eSIM требует **физическую eUICC в SIM-слоте**. Обычная SIM определяется отдельно; встроенная eSIM ZTE этим компонентом не поддерживается.

## Проверки и границы

Офлайн-проверки Mac: 114 сценариев подготовки, 44 проверки AppModel и 15 проверок выполнения сохранённого commit-сценария. В Windows проверены 30 сценариев принудительной подготовки и 204 проверки интерфейса. Общий установщик прошёл 68 файловых и процессных fixtures; после последнего изменения очистки отдельно прошли ещё четыре проверки, включая сохранение незавершённой загрузки. Эти тесты используют синтетическую среду и не заменяют запуск на модеме.

На подключённом B31 выполнена принудительная подготовка текущим установщиком: новый пароль агента проверен, установка завершена commit, незавершённого намерения не осталось. Подтверждены SSH 2222, строгая проверка ключа и совпадение устройства при двух свежих проверках USB/SSH. Ключи сервера и исполняемый файл работающего Dropbear сохранены. Проверены контрольные суммы исходного бэкапа и нового снимка перед принудительной заменой; новый снимок содержит предыдущий файл запуска. Контрольный временный каталог завершённой установки удалён, его журнал сохранён. Restore бэкапа, заводской сброс, запись IMEI и операции записи eSIM не выполнялись.

После принудительной подготовки производственный AppModel на Mac выполнил подключение и два последовательных обновления в одном процессе без перезапуска. Все три действия завершились с новым SSH-сеансом, той же идентичностью и загрузкой модема, без ошибок разделов; состояние занятости снято. Проверка карты eSIM не запускалась. Новая установка на B28, повтор после заводского сброса и нативный запуск Windows не подтверждены. Итоговые результаты и контрольные суммы будут лежать рядом с ZIP в каталоге `dist/1.24.6`.

В архиве SashaRIP для `FLY_CN_MU5250V1.0.0B13 / BD_FLYMODEMMU5250V1.0.0B28` проверка свежего бэкапа успешна: 173 записи. Следующий шаг подтвердил root ADB и остановился до запуска SSH. Для B28 требуется повторная подготовка исправленной Windows-сборкой. Нативный запуск Windows на компьютере SashaRIP в этой проверке не выполнялся.
