# 1.24.1 — длинные команды на старом ADB

Исправлена предварительная подготовка на модемах со старым ADB без `shell_v2`.
Такой ADB отклоняет длинную команду с `error: shell command too long`.
В 1.24.0 весь установщик передавался в аргументе `shell`; его предварительная
проверка поэтому не начиналась. Две попытки из диагностического архива
подтвердили тот же отказ, что и повторная проверка на подключённом модеме.

macOS и Windows заранее выбирают передачу через stdin для длинных команд.
Короткий приёмник подтверждает готовность, принимает ограниченный пакет,
проверяет полную длину и SHA-256 и затем выполняет команду. Результат имеет
отдельный маркер завершения. Обрыв не вызывает автоматического повтора.
Это применяется к подготовке и сбору сведений об устройстве.

Протокол поддерживает старый PTY: строки кодированного пакета ограничены,
эхо до начала результата отбрасывается. Содержимое stdin не записывается
в журнал. Ошибка длины ADB теперь сохраняется и для операций с закрытым
выводом; произвольные ответы операций с учётными данными остаются скрытыми.

На macOS сохраняется явно выбранный существующий файл доверия SSH при
переходе со старой сборки. Строгая проверка SSH-ключа остаётся обязательной.
Повторное использование доступного SSH проверяется отдельно от установки.

## Проверки и границы

Приёмник проверен на локальных shell/PTY и на подключённом модеме со старым
ADB: длинный UTF-8 скрипт, повреждённая передача, выход дочерней команды и
чтение stdin. Предварительная проверка реального установщика выполняется;
ошибки прав каталогов теперь видны как `INSTALL_ERROR DIRECTORY_MODE`.
Результат этой проверки не даёт разрешения игнорировать её условия.

Существующий SSH на проверенном модеме сопоставлен с USB по свежим данным
устройства, загрузки и компонентов. Полная переустановка агента на этом
модеме в ходе данной проверки не выполнялась. Агент и спецификация сбора
сохраняют версии 2.9.0-esim.1 и 7 соответственно.

Windows собирается для x64; аппаратный запуск исправления в Windows пока
не подтверждён. Новые архивы являются проверочной сборкой.
