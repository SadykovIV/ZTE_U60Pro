# Нумерация выпусков

Каждая следующая поставляемая сборка получает новый patch-номер: 1.24.5 → 1.24.6 → 1.24.7 → 1.24.8. macOS и Windows используют одинаковую версию выпуска. Проверки исходников не создают новую версию.

Текущая поставка — **1.24.8**: macOS build **49**, Windows FileVersion **1.24.8.0**. Номер build не заменяет patch-номер выпуска. Каталог готового комплекта — `dist/1.24.8`; ZIP, контрольные суммы и квитанции проверок сохраняются вместе. Предыдущие поставленные комплекты не перезаписываются.

В заметках отдельно указываются офлайн-тесты, проверка содержимого пакетов и реальные операции на модеме. Проверка B31 не означает успех на B28, после заводского сброса или в нативной Windows. Незавершённая аппаратная проверка остаётся явно отмеченной до получения результата.
