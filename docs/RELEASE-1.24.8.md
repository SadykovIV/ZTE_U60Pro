# 1.24.8 — проверка версии прошивки и установка агента

macOS **1.24.8 build 49**, Windows **1.24.8.0**, агент **2.9.0-esim.4**.

## Изменения относительно 1.24.7

- В «Подготовка модема → Подключение → Параметры подключения» возвращён флажок **«Не проверять версию прошивки»**. Он выключен по умолчанию и доступен для подготовки и последующих операций через SSH.
- В Windows выбранный режим передаётся в подключение, подготовку и операции с агентом. Общая сверка с B31 больше не останавливает установку агента при явно включённом флажке.
- Изменение настройки на Mac сбрасывает прежний сеанс; нужно подключиться снова. Настройку нельзя менять во время операции или работы терминала.
- На совместимом экранном интерфейсе флажок больше не блокирует установку страницы eSIM. Проверки конкретного интерфейса и компонентов сохраняются.
- В macOS диагностические утилиты также учитывают флажок. Их собственная проверка совместимости пакетов OpenWrt сохраняется.
- macOS проверяет целостность комплекта веб-панели до обращения к модему.

## Назначение флажка

Флажок отключает общую сверку прошивки с известным профилем. Остаются проверка устройства и SSH-ключа, права root, архитектура, целостность файлов, совместимость исполняемых компонентов и проверка результата установки. Специальные требования VPN, экранного расширения и операций с модемной памятью сохраняются.

Подготовка непроверенной Linux ARM64 прошивки использует измеренные свойства устройства. Установленный таким способом агент сохраняет режим диагностики `discovery`; флажок не переводит его автоматически в полный режим управления.

## Проверки и ограничения

Результаты тестов и проверки готовых ZIP находятся в `verification-summary.json` рядом с ними в `dist/1.24.8`.

Сценарии B28 проверяются на синтетических ответах транспортов. Устройство друга с B28 и нативная Windows недоступны для проверки в этой работе. Исправление подтверждённой общей блокировки не означает, что проверены все функции на B28. В старых логах SashaRIP есть отдельная ошибка `DROPBEAR_ABI`; подтверждённого журнала её повторения в 1.24.7 нет.

Управление eSIM требует **физическую eUICC в SIM-слоте**. Встроенная eSIM ZTE этим компонентом не поддерживается.
