# Зависимости операций

Состояние исходников после разделения операций, 7 октября 2026 года.
Все обычные операции настольной программы используют root SSH. ADB служит для
подготовки SSH. Постоянный агент нужен для управления через его веб-панель;
настольные IMEI, TTL, eSIM и VPN не требуют запущенного агента.

## Что требуется каждой операции

| Операция | Фактические зависимости | Постоянный агент |
| --- | --- | --- |
| Изменение IMEI | Готовый SSH, совместимый DIAG/NV/EFS-интерфейс, резервная копия перед записью и проверка результата. Подготовка SSH не запускается из этой операции. | Не нужен; запись доступна только в настольной программе. |
| TTL | Собственный скрипт настройки, iptables и проверенная работа ускорения IPA. | Не нужен. |
| eSIM: список, загрузка, удаление выключенного профиля | Физическая eUICC, доступный QMI/APDU-интерфейс. Программа передаёт временный helper в `/tmp/zte-desktop-esim-*` и вызывает `--esim-rpc`. HTTPS при загрузке идёт через компьютер. | Установленный или запущенный агент не нужен. |
| eSIM: активация профиля | Те же компоненты и поддержанный способ перечитать SIM через переключение радио. | Не нужен. |
| VPN: профили и управление | Собственные `/data/zte-vpn/vpnctl`, ядро mihomo, скрипты и настройки VPN. Программа вызывает контроллер по SSH. | Не нужен. |
| Установка агента | Проверенный исполняемый файл, его запуск и собственная веб-панель из комплекта. | Это отдельная операция; VPN и Launcher она не устанавливает и не обновляет. |
| Launcher: информация | Совместимый бинарник штатного экранного интерфейса и пакет Launcher. Данные читаются через ubus/proc. | Не нужен. |
| Launcher: VPN | Пакет Launcher; для работы управления нужен установленный VPN-контроллер. Установка страницы не устанавливает VPN. | Не нужен. |
| Launcher: eSIM | Пакет Launcher и актуальный исполняемый `/data/zte-agent`, вызываемый как `--esim-launcher`. | Нужен файл helper из комплекта агента; его постоянный процесс, автозапуск и веб-панель не требуются. |
| Логи и журналы | Локальные журналы доступны без модема. При готовом SSH добавляются журналы модема. | Не нужен. |
| Данные для адаптации прошивки | Готовый SSH для чтения файлов, структуры и возможностей устройства. | Не нужен; диагностика выполняется программой. |
| SSH-терминал | Root SSH, подтверждённые CID и boot ID, отсутствие выполняемой операции доступа/восстановления. | Не нужен; соответствие B31 для открытия терминала не требуется. |

Обычная SIM оператора не поддерживает хранение eSIM-профилей. Поддерживается
**съёмная физическая eUICC**, ранее проверялась 9eSIM V0. Запись профилей во
встроенную eSIM ZTE этим функционалом не поддерживается.

## Какие блокировки сохранены

- Выполняемая операция или открытый терминал не должны одновременно менять
  одни и те же файлы. Сохранены локальная и удалённая блокировки, сверка
  устройства и загрузки, проверка переданных файлов и результата операции.
- Незавершённые изменение IMEI или первоначальная настройка не блокируют
  независимые TTL, eSIM, страницы Launcher и SSH-терминал.
- Запись IMEI и снятие резервной копии NV/системных настроек сохраняют проверки
  собственных журналов IMEI/настройки: эти операции затрагивают общие NV/config
  данные. Подготовка SSH также не пересекается с незавершённой записью IMEI.
- Незавершённые очистка компонентов, восстановление образа и изменение доступа
  остаются основанием завершить восстановление перед конфликтующей записью.
  Неопределённый результат передачи не означает разрешение повторить запись.

## B31 и B28: границы совместимости

Известные идентификаторы устройств:

| Устройство | Firmware | Inner firmware |
| --- | --- | --- |
| Модем, на котором ранее проводились аппаратные проверки | `CN_ZTE_MU5250V1.0.0B31` | `BD_CNMU5250V1.0.0B31` |
| Присланные материалы SashaRIP | `FLY_CN_MU5250V1.0.0B13` | `BD_FLYMODEMMU5250V1.0.0B28` |

- Для русификации и Launcher имеются точные профили B31 и FLY B28. Выбор идёт
  по файлам экранного интерфейса. Совпадение названия прошивки само по себе
  не подтверждает совместимость патча.
- TTL сохраняет профиль B31: проверяются modem.b16, diag-router, версия
  iptables и инструменты IPA. VPN-контроллер сохраняет проверку B31 для
  изменений; чтение состояния и сведений о профиле выделено отдельно.
- eSIM: список, загрузка и удаление выключенного профиля не требуют B31-хэша.
  Активация с перечитыванием SIM и восстановление радио пока используют
  проверенный путь B31. Возможности конкретной карты проверяются отдельно.
- Запись IMEI использует существующий DIAG/NV/EFS-интерфейс. Windows дополнительно
  требует точного diag-router даже при отключённой проверке версии. В macOS
  флажок отключает сверку firmware/router; он не доказывает совместимость
  DIAG ABI и не превращает B28 в проверенную платформу для записи.

Снятие лишних зависимостей не подтверждает полную работу B28. В этой проверке
модем не изменялся; выполнены локальные регрессии с моделями транспорта.
Аппаратная работа VPN/TTL, запись NV, переключение радио и eUICC на B28, а также
запуск на нативной Windows остаются непроверенными.

## Проверка разделения операций

Локально прошли: macOS — 55 проверок состояния приложения, 21 TTL, 59 Launcher,
11 установки агента/панели, 15 opkg; Windows — 409 проверок общего сценария
установщиков/страниц/терминала. Проверены независимые журналы восстановления,
отсутствующий постоянный агент, отдельная установка компонентов, ошибки
передачи, сохранение резервных копий и сверка устройства.
