# 1.24.0 — проверка устройства перед подготовкой доступа

Проверочная сборка для macOS ARM64 и Windows x64. Агент: 2.9.0-esim.1.

## Что изменилось относительно 1.23.3

Программа сначала собирает технические сведения о выбранном устройстве.
Незнакомая прошивка, отсутствие root, CID, boot ID или части утилит не
останавливают доступные проверки. Отчёт разделяет прочитанные сведения,
доказанное отсутствие и невозможность проверки. Данные имеют источник;
в ZIP сохраняются результаты, команды, статусы, время и контрольные суммы.

46 ограниченных проверок охватывают ОС/ядро, ELF/загрузчики, init и автозапуск,
службы и схемы API, инструменты, общую структуру разделов и файловых систем,
доступные интерфейсы связи и признаки компонентов eSIM. Утилиты используются
по наличию, включая SHA-256 из BusyBox. Старые прошивки с CRCRLF в ADB также
обрабатываются корректно. Проверка не включает ADB и не меняет конфигурацию.

Подключение SSH больше не зависит от проверок IMEI. Первичная установка SSH
и агента через единственный доказанный root USB ADB не требует штатного Web API.
Перед каждым этапом проверяются выбранный канал, CID, boot ID и измеренные
компоненты; на устройстве выполняется отдельный текущий preflight. Сохранённый
отчёт не разрешает запись.

Для незнакомой прошивки поддерживаемая среда доступа определяется по условиям
Linux ARM64, каталогам/владельцам/монтированиям, свободному месту, доступным
инструментам, ELF и совместимости закреплённого Dropbear, запуску через procd
и rc.local, отсутствию незавершённых транзакций. Собственный агент или неизвестные
существующие helper-файлы сохраняются и требуют отдельного решения.

Диагностический режим агента не запускает миграцию конфигурации, восстановление
LAN, настройку USB или контроллер зарядки. Авторизация хранится в памяти.
Доступны явно разрешённые локальные чтения и информация о режиме; прочие
маршруты отклоняются до исполнения. Управление IMEI, eSIM, экраном, VPN и
восстановление сохраняют проверки своего адаптера.

## Проверка и границы

Сборка проверяется офлайн: команды спецификации на моделях разных сред,
неполная идентификация, отсутствие инструментов, отказ чтения, ELF32/64,
однозначный USB, потеря привязки, смена boot ID, preflight/транзакции/commit,
сохранение чужих файлов, режим агента и GUI. HTTP-проверка выполняется локально
на loopback с авторизацией и отказом изменяющих маршрутов. Контрольные суммы
ресурсов и соответствие архива исходникам проверяются перед упаковкой.

Модем друга находится у него на Windows. Эта сборка ещё не проверена на его
устройстве или в работающей Windows. Часть Linux-данных недоступна на Mac,
поэтому локальная проверка HTTP подтверждает обработку недоступности, а не
состояние оборудования. Полное применение/восстановление и аппаратные функции
на неизвестной прошивке не объявляются проверенными.

Первый шаг на модеме друга: открыть «Проверить устройство», выбрать USB ADB и
экспортировать ZIP. Результат покажет фактическую среду и оставшиеся условия.
