# ZTE U60Pro Manager — macOS и Windows x64

Приложение SwiftUI для **macOS 13+ / Apple Silicon** и отдельная версия
Avalonia для **Windows x64**. Готовая `.app` не требует Python, Homebrew и Node.js.
Windows portable включает .NET и инструменты ADB/SSH; распакуйте весь ZIP,
сохранив папку `Resources` рядом с EXE. Intel Mac пока не поддерживается. Требования к модему и первичные
источники приведены [в начале README](../README.ru.md#требования-к-модему).

## Подготовка и агент

Пароль веб-интерфейса вводит владелец; он не входит в дистрибутив и не сохраняется
в настройках приложения. Первоначальная подготовка последовательно проверяет
**готовый SSH → root USB ADB → штатный USB debug через Web → способ через бэкап**.
После неудачи способа программа проверяет следующий и записывает причину в журнал.
Имена прошивок не ограничивают эту последовательность. Для установки нужны
фактические root-доступ и совместимая Linux ARM64-среда. Известный платформенный
ключ бэкапа проверяется автоматически; backup-key suffix — необязательная ручная
замена, которая не сохраняется. До восстановления проверяются расшифровка,
архив, контрольные суммы и узнаваемый штатный USB-блок rc.local.
Для SSH создаётся отдельная пара ключей;
доверие к хосту устанавливается через проверенное USB-подключение.

При готовом SSH повторная подготовка не нужна; незавершённую операцию можно
продолжить через её журнал. Обычное управление, информация и свежая диагностика
используют только SSH. При ошибке программа не выбирает другой канал автоматически.
Штатный Web и веб-панель агента открываются в браузере.

Во вкладке «Подключение» блок **«Доступные способы подключения»** показывает
проверки каналов, браузерные ссылки и переключатель **«Включить ADB»**.
Состояние USB ADB читается по SSH: неизвестное состояние не считается выключенным.
На проверенной B31/configfs-конфигурации переключатель меняет только ссылку ADB;
другие USB-функции, идентичность устройства и сеанс загрузки проверяются до и после.
USB-сеть может кратковременно отключиться. Модем ожидает подтверждения по SSH
до 60 секунд и без него выполняет одну попытку отката. При неопределённом исходе
журнал сохраняется, повторная запись запрещается. Изменение временное, до перезагрузки.

Если SSH нет, поддерживаемое включение ADB через штатный Web остаётся частью
первоначальной подготовки. Внутренние ADB-проверки перед установкой сохранены;
они не используются как запасной канал обычной диагностики.
[Методы подготовки и ограничения](ADB-PREPARATION.md).

Предварительная подготовка устанавливает агент и SSH в совместимой Linux
ARM64-среде. Исследование прошивки выполняет программа через SSH и не требует
агента. Агент предоставляет информацию и управление для веб-панели и страниц
модема; необходимые компоненты проверяются при конкретной операции. Установщик получает
проверенный статический инструмент ограничения времени, поэтому не требует
системной команды `timeout`. Хеши, ELF ABI, права, структура каталогов и
идентичность проверяются перед записью. VPN устанавливается отдельно.

Кнопка выбора своего агента принимает Linux ELF64 ARM64 до 64 MiB. Перед заменой
проверяются архитектура, структура и SHA-256; предыдущий бинарник сохраняется.
Существующие пароль, SSH, автозапуск и VPN-профили не заменяются. Доступны откат и
восстановление прерванной операции. Совместимость API произвольного агента с
панелью не гарантируется одной лишь корректностью ELF.

Русификация заменяет китайский слот на русский и уменьшает шрифт русского текста.
Исходный исполняемый файл читается с вашего модема: в дистрибутиве только небольшой
патч с проверками исходных/итоговых хэшей, переводы и установщик.

## eSIM

В программе и веб-панели доступны загрузка, список, выбор активного и удаление выключенного профиля. Нужна **физическая eUICC в SIM-слоте**; проверена 9eSIM V0/B31. Встроенная eSIM ZTE не поддерживается. Программа использует интернет компьютера, веб-панель — модема. [Режимы, журнал и ограничения](ESIM-DESKTOP.md).

## IMEI и TTL

Смена IMEI запускается отдельно, только из программы при готовом подключении
по SSH. Эта кнопка не запускает подготовку модема или установку агента.
Перед записью программа принудительно сохраняет оба NV550 и EFS `/config`,
привязывает операцию к устройству, проверяет данные, выполняет запись с полным
чтением результата и возвращает исходную защиту. Может потребоваться две
перезагрузки. Это **не QCN и не полный образ всех разделов**; расширенные виды
копирования доступны отдельно в администрировании. Прерванную операцию следует
возобновить через её журнал, а не запускать повторную запись вручную.

Исходящий TTL устанавливается **точно** (например, 64), входящий **увеличивается
на N** (например, +1). Настройка применяется на модеме и переживает перезагрузку.
Она касается IPv4; управление IPv6 Hop Limit не заявлено. Аппаратное ускорение,
обходящее правила, выключается проверенным менеджером.

## VPN и приложения

VPN-компоненты поставляются без профилей и устанавливаются отдельно от агента
и страниц Launcher. Программа по SSH и веб-панель агента работают с одним
набором профилей: список, импорт, активация, переименование и удаление.
В программе можно вставить VLESS-ссылку или выбрать текстовый файл с одной
ссылкой. Импорт сохраняет профиль без активации; активный профиль удалить нельзя.
При первой активации контроллер настраивает и включает отдельный VPN Wi-Fi,
о чём сообщает подтверждение. Имя и пароль сети меняются при выключенном VPN Wi-Fi.
Новая сеть по умолчанию называется **ZTE-VPN** и получает пароль основного Wi-Fi
на момент первой настройки. Подробнее: [агент](AGENT.md).

Проверенный каталог сейчас содержит htop и экспериментальный opkg. Объём
фактических испытаний указан в [каталоге](../Catalog/README.md). Подписанный список
обновляется отдельно от программы; он может разрешать только уже встроенные
установщики и версии. Установленные приложения вне списка остаются видимыми
и доступными для удаления. SSClash-Go пока не одобрен в каталоге; его бинарник
не распространяется. Он не требуется нашему VPN.

## Данные, диагностика, восстановление

Данные Mac находятся в `~/Library/Application Support/ZTE IMEI Studio`.
Данные Windows находятся в `%LOCALAPPDATA%\ZTE IMEI Studio`.
SSH-ключи, копии NV/EFS и конфигурации остаются локальными. Резервные копии могут
содержать секреты — храните их отдельно от публичных отчётов.

Журнал включает этапы операций, время, запросы, коды завершения, ограниченные
выводы команд, версии и хэши компонентов. Просмотр журнала остаётся в
«Администрирование → Журнал действий», а общий сбор и экспорт находится в
«Подготовка модема → Диагностика».

В диагностике доступны два действия:

- **«Логи и журналы»** сохраняет действия программы, подготовку, соединения,
  ошибки операций и установочные логи. При подключении по SSH добавляются
  свежие системные журналы, журнал ядра и журналы компонентов модема.
  Без подключения или при ошибке чтения сохраняются локальные данные с причиной.
- **«Данные для адаптации прошивки»** собирает свежую проверку устройства,
  структуру и возможности прошивки, до 40 файлов компонентов и очищенные
  журналы в один ZIP. Подробности проверок находятся в архиве; на экране —
  ход сбора и итог. Требуется SSH, постоянный агент не нужен.

Постоянный журнал Windows ведётся с 1.24.4; закрытые сеансы старых версий
восстановить нельзя. Сбор данных сам по себе не подтверждает совместимость
операций записи. [Состав набора для адаптации](FIRMWARE-ADAPTATION-DATA.md).

Из ZIP исключаются ключи, бэкапы и хранилища профилей; известные секреты и IMEI
маскируются. Содержимое любых внешних логов не может быть гарантированно
обезличено. [Формат диагностики macOS](../MacIMEI/DIAGNOSTICS.md).

Восстановление после сбоя не означает гарантированное восстановление повреждённой
прошивки. Программа не заменяет штатные средства восстановления устройства.

## Launcher и opkg

В Launcher доступны «Информация о модеме», «Управление VPN» и eSIM. Страницы выбираются галочками, их порядок задаётся отдельно. eSIM-страница показывает профили и позволяет переключать их с перечитыванием карты.
Информационная и VPN-страницы не требуют постоянно работающего агента.
Для eSIM-страницы нужен актуальный исполняемый компонент eSIM из комплекта
агента; страница запускает его по запросу. Установка страниц не обновляет VPN
или агент автоматически. [Зависимости операций](OPERATION-DEPENDENCIES.md).

Информационная страница показывает до 12 выбранных показателей, с перетаскиванием
порядка, прокруткой и видом «плитки»/«список». Настройки сохраняются на модеме.
VPN-страница показывает реальные гостевые SSID. Имя и пароль изменяются только
по явному сохранению при выключенном VPN Wi-Fi; существующая сеть не переименовывается автоматически.

opkg устанавливает пакеты в отдельное дерево `/data`; штатный `/bin/opkg` не
заменяется. База пакетов — OpenWrt 23.05.4 / `aarch64_cortex-a53`. Терминал
предоставляет полноценный SSH shell; команды от имени root могут менять модем.
Встроенный редактор источников не импортирует новые ключи подписей.
Windows VPN-установщик требует штатный `flock`; диагностические приложения и
opkg используют собственную атомарную блокировку.

## Полные образы

Копируются основная область eMMC и boot0/boot1, с проверкой размеров и SHA-256.
RPMB/OTP не входят в копию, снимок работающей системы не атомарен.
В Windows доступны создание и проверка; полное восстановление пока не реализовано.
В macOS восстановление требует отдельно загруженной среды восстановления.
Её образ и автоматическая загрузка не входят в комплект. Запись поверх
работающей системы запрещена. Функция не заменяет аппаратное восстановление.

Внизу боковой панели находятся выбор Русский / English и «О программе».
В подготовке доступны четыре вкладки: «Подключение», «Диагностика», «Агент»
и русификация экрана модема. Общие проверки расположены в
«Подготовка модема → Диагностика» на одной странице. Способы подключения
и ADB собраны в компактном раскрывающемся блоке вкладки «Подключение». Диагностические утилиты остаются
в «Приложениях»; проверки eSIM и VPN — на своих страницах.
Вход в Terminal автоматически открывает SSH-сеанс при готовом подключении;
для установки пакетов предварительно установите opkg.
