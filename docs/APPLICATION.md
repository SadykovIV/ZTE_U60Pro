# ZTE IMEI Studio — программа для macOS

Нативное приложение SwiftUI для **macOS 13+ / Apple Silicon**. Готовая `.app`
работает без Python, Homebrew, Node.js и исходного проекта. Для Windows и Intel
Mac сборка этой программы пока не выпускается. Требования к модему и первичные
источники приведены [в начале README](../README.md#требования-к-модему).

## Разделы

| Меню | Возможности |
| --- | --- |
| О модеме | Модель, прошивка, система, RAM, хранилища, состояние служб, диагностические разделы и ZIP |
| Подготовка модема | Подключение, включение ADB через проверенный бэкап, SSH, штатный/пользовательский агент, русификация экрана |
| IMEI | Чтение двух номеров, проверка формата, обязательная копия NV550/EFS перед изменением, сохранённые копии и возобновление прерванной операции |
| TTL | Точное исходящее значение IPv4 TTL и прибавление N к входящему TTL; независимое включение направлений |
| VPN | Проверка, установка и обновление Mihomo, контроллера, панели и страниц штатного экрана. Импорт профилей выполняется в агенте |
| Приложения (beta) | Место в `/data`, каталог, установка и удаление поддерживаемых приложений с проверкой принадлежности |
| Администрирование | SSH-пользователи, доступы, конфигурационные/модемные/пользовательские бэкапы, подробный журнал действий |

## Подготовка и агент

Пароль веб-интерфейса и backup-key suffix вводит владелец. Они не входят в
дистрибутив и не сохраняются в настройках Mac. Подготовка проверяет устройство,
сохраняет исходный зашифрованный бэкап, меняет только разрешённый элемент
автозапуска ADB и проверяет результат. Для SSH создаётся отдельная пара ключей;
доверие к хосту устанавливается через проверенное USB-подключение.

Кнопка выбора своего агента принимает Linux ELF64 ARM64 до 64 MiB. Перед заменой
проверяются архитектура, структура и SHA-256; предыдущий бинарник сохраняется.
Существующие пароль, SSH, автозапуск и VPN-профили не заменяются. Доступны откат и
восстановление прерванной операции. Совместимость API произвольного агента с
панелью не гарантируется одной лишь корректностью ELF.

Русификация заменяет китайский слот на русский и уменьшает шрифт русского текста.
Исходный исполняемый файл читается с вашего модема: в дистрибутиве только небольшой
патч с проверками исходных/итоговых хэшей, переводы и установщик.

## IMEI и TTL

Перед записью IMEI программа принудительно сохраняет оба NV550 и EFS `/config`,
привязывает операцию к устройству, проверяет данные, выполняет запись с полным
чтением результата и возвращает исходную защиту. Может потребоваться две
перезагрузки. Это **не QCN и не полный образ всех разделов**; расширенные виды
копирования доступны отдельно в администрировании. Прерванную операцию следует
возобновить через её журнал, а не запускать повторную запись вручную.

Исходящий TTL устанавливается **точно** (например, 64), входящий **увеличивается
на N** (например, +1). Настройка применяется на модеме и переживает перезагрузку.
Она касается IPv4; управление IPv6 Hop Limit не заявлено. Аппаратное ускорение,
обходящее правила, выключается проверенным менеджером.

## VPN и приложения

VPN-компоненты поставляются без профилей. После их установки агент позволяет
импортировать, выбирать, переименовывать и смотреть параметры профилей.
Новая сеть по умолчанию называется **ZTE-VPN** и получает пароль основного Wi-Fi
на момент первой настройки. Подробнее: [агент](AGENT.md).

SSClash-Go — необязательное приложение, не требуется нашему VPN. Его лицензия
запрещает перепубликацию бинарника: кнопка «Установить» загружает закреплённый
официальный релиз **v6.4.1** непосредственно с GitHub и проверяет размер, SHA-256
и ELF. Только эта дополнительная установка требует интернета на Mac.

## Данные, диагностика, восстановление

Данные Mac находятся в `~/Library/Application Support/ZTE IMEI Studio`.
SSH-ключи, копии NV/EFS и конфигурации остаются локальными. Резервные копии могут
содержать секреты — храните их отдельно от публичных отчётов.

Журнал включает этапы операций, время, запросы, коды завершения, ограниченные
выводы команд, версии и хэши компонентов. Экспорт ZIP доступен офлайн и вместе
со свежей диагностикой модема. Из ZIP исключаются ключи, бэкапы и хранилища
профилей; известные секреты и IMEI маскируются. Содержимое любых внешних логов
не может быть гарантированно обезличено. [Формат диагностики](../MacIMEI/DIAGNOSTICS.md).

Восстановление после сбоя не означает гарантированное восстановление повреждённой
прошивки. Программа не заменяет штатные средства восстановления устройства.
