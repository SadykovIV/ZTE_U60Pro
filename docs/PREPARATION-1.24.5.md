# 1.24.5 build 46: общая подготовка и ключ бэкапа

macOS **build 46**, Windows **1.24.5.0**, агент **2.9.0-esim.4**.

После сброса модема подготовка доходила до B31 backup/restore и требовала ручной
ввод ключа, который уже был найден при исследовании. При подготовке публичной
версии этот известный платформенный суффикс был исключён вместе с приватными
данными владельца. Теперь приложение содержит его как платформенную константу.
IMEI и пароль штатного Web читаются или вводятся для выбранного устройства.

Пустое поле выбирает известный ключ на любой прочитанной прошивке. Его
применимость подтверждается по скачанному архиву, а не по имени версии.
Непустое поле — ручная замена: неправильное значение не подменяется автоматически.
Алгоритм архива остаётся прежним: проверка Salted__, расшифровка, gzip/tar,
внутренний MD5, состав и метаданные, изменение только строки ADB в rc.local,
повторное шифрование и контрольное расшифрование. Перед правкой проверяется
канонический штатный USB-mode блок, включая отсутствие дополнительных действий
с usb_op. Это выполняется до загрузки.
Оригинальный зашифрованный бэкап сохраняется локально.

Уже работающие SSH/ADB и продолжение после отправленного восстановления
не требуют повторной расшифровки и не отправляют восстановление заново.
Персональные IMEI, пароли, SSH-ключи и доверие пользователя в дистрибутив не входят.

## Проверка

Найденный ключ проверен офлайн на историческом исходном B31-бэкапе: результат
расшифровки побайтно совпал с сохранённым оригиналом. Внешний архив содержит
ожидаемые два файла, внутренний MD5 совпадает; внутри 174 записи и один обычный
etc/rc.local. Приватные файлы устройства в репозиторий не добавлялись.

После нового сброса проверена доступность штатного Web: HTTP 200.
Новая полная подготовка с восстановлением и установкой SSH на устройстве
в этом цикле пока не проверена. Нативный запуск Windows также не подтверждён.

## Подготовка ранних и других прошивок

Программа проверяет **готовый SSH → root USB ADB → штатный USB debug через Web →
способ через бэкап**. После отказа способа проверяется следующий. Для нового SSH
проверяется фактическая Linux ARM64-среда. Совпадение прошивки с B31/B02 и
владельческими хэшами не требуется для этой подготовки; ограничения отдельных
операций с IMEI, радио и экраном сохраняются.

| Проверка | Результат |
| --- | --- |
| macOS Onboarding / BackupPatch / AppModel / runtime locale | 105 / 20 / 38 / 6 проверок PASS |
| Windows core / production UI RU+EN | 224 / 170 проверок PASS |
| Исходный зашифрованный B31-бэкап | PASS: 174 записи, только ожидаемая правка загрузки, повторная обработка без изменений |
| Отказ direct → проверенный backup → generic installer | PASS на тестовых транспортах для ранних и других прошивок |
| Неверный ключ, повреждённый архив, неизвестный или неоднозначный USB-блок | Отказ до загрузки/восстановления |
| Обрыв при переходе к установщику | Сохранён журнал уже отправленного restore; повторной отправки нет |

Windows UI проверялся на macOS с тестовыми службами. Нативный Windows,
FLYMODEM B28 и полный новый Web/restore/install-цикл после сброса не запускались.
Контрольные суммы готовых пакетов и результаты проверки их содержимого
поставляются рядом с ZIP в каталоге `1.24.5-build46`.

Результат FLYMODEM B28 на устройстве ожидается:
в журналах SashaRIP нет исходного зашифрованного бэкапа для проверки ключа.

## Проверка ключа без изменений модема

В параметрах первоначальной подготовки есть **«Проверить ключ бэкапа»**.
Нужны адрес модема и пароль штатного Web. SSH, ADB и пароль агента не требуются.
Проверка сохраняет свежий зашифрованный оригинал, сверяет устройство до и после
копирования, затем проверяет расшифровку и структуру архива в памяти.

При пустом поле пробуется известный платформенный суффикс; при непустом —
строго введённое значение. Проверка доступна независимо от имени прошивки.
Она не включает ADB, не загружает изменённый архив, не восстанавливает настройки,
не перезагружает модем и не устанавливает SSH. Положительный результат
подтверждает ключ и формат именно свежего бэкапа; права на запись не меняются.
Для SashaRIP это позволит проверить FLYMODEM B28 без переноса предположений B31.

[Источники ключа и исследование других прошивок](BACKUP-KEY-RESEARCH.md).

## Проверка у SashaRIP

Точная пара устройства: `FLY_CN_MU5250V1.0.0B13` /
`BD_FLYMODEMMU5250V1.0.0B28`.

1. Распаковать весь Windows portable ZIP и открыть приложение.
2. В параметрах первоначальной подготовки указать адрес и пароль штатного Web.
   Оставить Backup-key suffix пустым.
3. Выполнить «Проверить ключ бэкапа». В результате должны появиться обе версии,
   число записей и SHA-256. На этом этапе настройки модема не меняются.
4. Для первоначальной подготовки задать пароль нового агента и выполнить
   предварительную подготовку. Программа проверит доступные способы по очереди.
5. Сохранить журнал приложения и общий диагностический архив с результатом.
   При отказе не удалять журнал незавершённой операции: он хранит уже отправленные
   действия для продолжения без повторного восстановления.

Успешная проверка ключа подтверждает только расшифровку и формат скачанного
архива. Перед восстановлением программа отдельно проверяет загрузочный скрипт;
перед установкой — реальную среду и привязку USB-устройства.
