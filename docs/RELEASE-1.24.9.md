# 1.24.9 — быстрое подключение и чистая установка после сброса

macOS **1.24.9 build 50**, Windows **1.24.9.0**, агент **2.9.0-esim.4**.

## Изменения относительно 1.24.8

- Подключение проверяет SSH, платформу, CID и текущую загрузку двумя короткими запросами. Прошивка, NV, агент, VPN, лаунчер и приложения проверяются при выборе соответствующей операции.
- Нажатие «Проверить агент» читает состояние через SSH без загрузки файлов на модем. Проверка русификации также доступна независимо от незавершённой подготовки или смены IMEI.
- Независимую русификацию можно установить при наличии журналов подготовки и IMEI. Её собственные проверки интерфейса, файлов и активной блокировки сохраняются. Операции с NV по-прежнему проверяют свой журнал.
- При ошибке русификации показывается конкретная причина: отсутствующий автозапуск, изменённый штатный скрипт, незавершённое изменение или неработающий процесс экрана.
- Флажок **«Чистая установка после заводского сброса»** размещён рядом с кнопкой подготовки и выключен по умолчанию. Он включает принудительную переустановку агента и SSH с заданным новым паролем, резервное копирование компонентов программы и очистку их данных и временных файлов. Значок **ⓘ** объясняет действия и назначение флажка.
- При явной чистой установке программа может завершить прежний готовый установщик после проверки устройства, его файлов, процесса и резервной копии. Прежний журнал сохраняется. Затем начинается новая установка. Старый пароль не используется для подтверждения новой установки.
- Общий флажок **«Не проверять версию прошивки»** из 1.24.8 сохранён.

## Проверка на модеме B31

Проверена чистая переустановка после пользовательского заводского сброса: новый пароль подтверждён, SSH работает на порту 2222, копия компонентов скачана и проверена перед очисткой. Быстрое подключение в этой проверке заняло около 0,72 секунды. Агент проверен отдельно; русский интерфейс восстановлен и включён.

Точные результаты тестов, исходники сборки и контрольные суммы пакетов находятся в `verification-summary.json` рядом с ZIP в `dist/1.24.9`.

Windows проверяется офлайн и по содержимому пакета; нативная Windows и модем B28 в этой работе недоступны. Проверка B31 не подтверждает все функции других прошивок.

Чистая установка затрагивает компоненты нашей программы. Штатные данные модема, IMEI и профили SIM/eSIM сохраняются. Управление eSIM требует **физическую eUICC в SIM-слоте**; встроенная eSIM ZTE этим компонентом не поддерживается.
