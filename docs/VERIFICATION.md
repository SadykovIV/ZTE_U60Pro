# Проверка начальной публичной сборки — 24 сентября 2026

Текущий выпуск: [1.20.0](RELEASE-1.20.0.md). Ниже сохранён отчёт начальной публикации.

Сборки: ZTE IMEI Studio **1.9.1**, ZTE Agent **2.7.1**, VPN controller **1.2.1**.
Тесты выполнялись локально, без записи на модем и без изменения рабочего проекта.

- Rust: **81 тест** (агент, process-runner, VPN-контроллер), без ошибок.
- React: **29 тестов**, TypeScript/Vite production build и ESLint — успешно.
- Подготовка модема: **30 тестов**, включая отсутствие сетевых запросов при пустом backup-key suffix.
- IMEI/EFS: **33 теста** на синтетическом config и тестовых IMEI; реальные дампы исключены.
- Каталог приложений: **34 теста**, включая отказ от неизвестного источника загрузки. Официальный SSClash использован только как внешний тестовый файл и не входит в Git или сборки.
- DiagnosticArchiveTests, AgentInstallationTests, BackupPatchTests — успешно.
- Установка/откат агента: **8** shell-тестов; обновление VPN-контроллера и configure.lua с откатом: **3**; установщик страниц экрана: **5**.
- C-помощники: шесть групп тестов NV/EFS/транзакций, включая **22** сценария EFS.
- Проверены подпись ad-hoc, целостность ZIP, ARM64 ELF, ресурсные хэши и соответствие Swift-исходников build-manifest.json.
- Gitleaks **8.30.1**: утечек в снимке публикуемых исходников не найдено. Исключения ограничены файловыми SHA-256 и хэшем синтетического пароля в тесте.
- Рекурсивный аудит исходников и архивов: персональные данные исходного проекта не обнаружены, SSClash-бинарник отсутствует.

В неизменённом архиве исходников upstream Mihomo есть публичный тестовый ключ
в `transport/openvpn/config_test.go`. Это тест разбора OpenVPN-конфигурации,
не ключ владельца модема; файл не устанавливается. Аудит разрешает исключительно
точный SHA-256 этого файла и отдельно учитывает его. Рабочих VPN-профилей,
паролей, SSH-ключей или доверенных хостов пользователя в релизе нет.

Проверки не заменяют испытание этой публичной сборки на каждой прошивке.
Живые подтверждения базовых функций относятся к исследованной B31, а не к
любой прошивке с отключённой проверкой совместимости.
