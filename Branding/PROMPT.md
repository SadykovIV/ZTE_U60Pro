# ZTE U60Pro Manager icon

Generated locally with ImageGen from the official UserGate symbol and the supplied cellular signal reference. The signal sheet was used only as a conceptual reference for original ascending bars.

## Prompt

Use case: logo-brand. Create one polished square desktop app icon for ZTE U60Pro Manager, designed to look superb at 40px in a navy desktop sidebar and at 128px in a dock. Image 1 is the official UserGate symbol reference: the interlocking blue and dark vertical rounded strokes are the recognizable brand anchor; preserve this visual identity. Image 2 is only a conceptual reference for ascending mobile signal strength bars, not a sheet to reproduce. Invent an original, unified composition combining the UserGate interlocking rounded vertical strokes with a small ascending 5-bar mobile signal motif, integrated into ONE simple balanced geometric emblem. Generous negative space, crisp precise edges, centered emblem, thick readable strokes. Palette: vivid corporate UserGate blue #0C89DB, light cyan #3EB6E2, cool steel #4C7EA5, on deep navy #081528. Rounded-square app tile, restrained subtle depth, elegant light on upper edges, mostly flat vector-like geometry, no glossy plastic, no mockup or perspective. No text, no letters, no numbers, no extra badges, no labels, no watermark, no reference sheet. This is a new original app icon, not an edit of the signal illustration. Output 1024x1024, tile filling canvas with clean rounded corners and genuinely transparent pixels outside the rounded-square silhouette.
