# ZTE Agent 2.8.0

[Описание агента](../docs/AGENT.md) · [Требования к модему](../README.md#требования-к-модему) · [Сборка](../docs/BUILD.md)

Агент для Linux ARM64 входит в ZTE IMEI Studio 1.19.0. Комплект содержит
веб-панель 2.8.0, VPN-контроллер 1.3.0 и расширение штатного Launcher B31.
Новые страницы Launcher показывают выбранные показатели модема в виде списка
или плиток с прокруткой. VPN-контроллер читает настоящую Guest Wi-Fi сеть и
применяет её имя/пароль с проверками и восстановлением при ошибке.

Установка агента и SSH выполняется при предварительной подготовке; VPN —
самостоятельная операция из приложения. Собственный пароль задаёт владелец.
Публичный комплект не содержит пользовательских профилей, ключей, бэкапов,
полных файлов штатного UI или шрифта прошивки.

Сборка из корня репозитория обновляет всю цепочку SHA-256:
Launcher → VPN-контроллер → агент → ресурсы приложения. Для изменений встроенных
компонентов используйте полный `python3 tools/build.py`.
